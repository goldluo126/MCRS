## 2. 数据层

### 2.1 主源裁决（v3 冻结禁令）

- **原生全链路原则**：主实验 MUST 在单一供应商的原生题材体系内端到端运行（题材定义、成分、历史快照同源）。**MUST NOT 将某供应商动态成分映射到另一供应商概念代码后作为主真相源**（跨源映射 = 名称匹配主观性 + 一对多 + 时变映射 + 今日语义解释过去的前视）；
- **主源选定判据**（普查 `CONCEPT_DATA_CENSUS.md` 实测后机械触发）：① 带日期历史快照可得性（硬门槛；据官方文档预判：`dc_member` 支持 trade_date 历史、`kpl_concept_cons` 含 trade_date、`ths_member` in/out 日期"暂无"——普查实测为准）；② 时段覆盖；③ 语义匹配（叙事标注 > 分类学）；
- **角色分配**：主源 = 满足①②的原生源（预判 KPL 或 DC）；第二源 = 稳健性复现（在另一原生体系内独立重跑主判据，不映射）；THS = 交叉校验与前瞻快照，永不做主真相源；
- 三源一致度诊断（谢林收敛度，v2.1 遗产）保留：触发题材的跨源核心成分交集比例，作事件级伴随测量。

### 2.2 创设偏差处置 v3（替代 60 日缓冲）

- 快照覆盖区内：概念/题材在日 D 合格，当且仅当**它出现在 ≤D 的真实快照中**；成分一律取 ≤D 最近快照，禁止任何回填；

- 无快照覆盖的区间：禁止用于任何判定（连方向性参考都须标 `no_snapshot` 并置于附录）；
- **偏差解读律修订**（吸纳审查）：`member_backfill=true` 或本体错误可能双向扭曲——PASS 是弱证据；**FAIL 仅对"本实现"是证据，不自动升级为对"假设家族"的强证据**；家族级判决只能出自干净 PIT 的第一法庭。

## 3. 题材事件 Episode 与协调跃迁过滤器

### 3.1 核心量：涨停富集冲击 LUShock（替代原始涨停家数）

```
对题材 c、日 D、其合格成分 i（可交易，属交易板块 b(i) ∈ {主板10%, 创业板20%, 科创板20%, 北交所30%}）:
  p_{b,D}   = 板块 b 当日全市场涨停率 = 全市场板块 b 涨停数 / 板块 b 可交易股数
  E_c       = Σ_i p_{b(i),D}                    # 板块分层的期望涨停数
  V_c       = Σ_i p_{b(i),D}(1 − p_{b(i),D})    # Poisson-binomial 方差
  Z_LU(c,D) = (LU_{c,D} − E_c) / sqrt(V_c + 1e-9)
```
- 触板判定沿用：close_raw ≥ up_limit 封板；high_raw ≥ up_limit ∧ close_raw < up_limit 炸板（pre-2019 回退规则沿用）；
- `BombRate`：触板数 <3 时不定义（中性，不参与条件）；≥3 时 = 炸板数/触板数；
- `MaxBoard`：保留原始值（其角色是"梯队存在晋级"的结构判断，非强度量，不做标准化——设计留痕）。

### 3.2 Episode 状态机（本版核心）

```
状态定义（题材 c 逐日评估，全部 ≤D 数据）:

DORMANT（休眠，点火的前提）:
  过去 20 交易日内：Z_LU(c,t) ≥ 2 的天数 ≤ 1              # R-D1
  且 CrowdPctl(c,D-1) < 0.80                               # R-D2（份额分位未处高位）

IGNITION（点火）:
  DORMANT 成立的次日起，首次 Z_LU(c,D) ≥ 3                 # R-I1（约 P≤1e-3 的富集异常）
  → 创建 EpisodeID = (ConceptCluster, D_ignition)，EpisodeAge 从 0 起算

CONFIRMATION（早期确认，进场窗）:
  EpisodeAge ∈ [1, 4] 内出现任一:                           # R-C1 进场窗上限 4
    ① 扩散：Z_LU ≥ 2 再现，且新增涨停成员 ≥ 1（非同批个股）
    ② 晋级：MaxBoard 较点火日抬升（出现 ≥2 板）
  且 BombRate ≤ 0.5（定义时）
  → TRIGGER（进场信号，D+1 执行）；每 Episode 至多触发一次

MATURITY / 退潮（新开仓禁区）:
  EpisodeAge > 4，或 CrowdPctl > 0.90，或 ΔZ_LU 连续 2 日为负且 BombRate > 0.5
  → 本 Episode 不再产生进场信号；同一 ConceptCluster 重新进入 DORMANT 并再点火 → 新 EpisodeID
```

- **研究问题由此改写**："哪个此前休眠的题材刚刚发生异常协调跃迁、且仍处事件早期？"（而非"哪个题材当前最协调"）；
- `F-ATT 龙虎榜关注广度`（更名自"席位集团化"，审查 §4.2/4.3 采纳）：[D-4,D] 内龙虎榜正净买入的不同成分数 ≥2——**降级为并列诊断与同分决胜（tiebreaker），不进触发条件**（上榜内生于涨停，非独立证据）；
- **席位重叠度增强项（登记未启用）**：基于 `top_inst`（营业部明细，已实测存在）构造 SeatOverlap（成分间买入席位 Jaccard 均值），须先完成席位清洗（剔除拉萨系散户通道/机构专用/量化通道标注）；晋升进过滤器须走新登记。

## 4. 载体：大容量题材核心（ZJ v3）

**合格池（全部硬约束，零权重参数）**：触发 Episode 的题材成分中，同时满足——

| 轴 | 约束 |
|---|---|
| 容量 | 自由流通市值 ≥ 50 亿元 ∧ ADV20 ≥ 3 亿元 |
| 题材纯度 | 出现在 ≥2 个数据源的该题材成分中，**或** 本 Episode 内其涨停/异动原因标注与题材一致（主源 desc/涨停原因字段） |
| 资金参与 | Episode 起点至 D 累计超额收益 > 0 ∧ 换手率较自身 20 日均值放大 ≥ 1.2 倍 |
| 未过热护栏 | D 日收盘非涨停 ∧ Episode 内涨停次数 ≤ 1 ∧ Episode 累计涨幅 < 40% |
| 可交易 | 非停牌/非 ST/非退市整理 |

**选取**：池内按 [D-4,D] 五日成交额降序取前 2（Z1/Z2）；D+1 开盘涨停/停牌 → 顺位替补至第 4 名；仍不足则少买，记 `dropped_zj`。池为空 → 该事件跳过，记 `zj_pool_empty`（诊断题材纯度约束的杀伤率）。
入场：D+1 开盘价，副口径 D+1 VWAP 并报；权重：每事件 Z1/Z2 各半，组合并发 ≤6 事件。

## 5. 五臂匹配设计（修订归因）

| 臂 | 题材 | 选股 | 回答 |
|---|---|---|---|
| **T** | 触发 Episode | ZJ 规则（§4 全池+排序） | 端到端 |
| **A** | **匹配非触发题材**（见下） | ZJ 规则 | 过滤器效应 H-Z2 |
| **B** | 触发 Episode | **同一 ZJ 合格池内均匀随机**（仅取消排序；200 次重复） | 排序效应 H-Z3 |
| **N** | 触发 Episode | **同一 ZJ 合格池内** 20 日 RS 前 2 | ZJ vs 动量 H-Z4 |
| （影子 L） | 触发 Episode | MaxBoard 龙头（不交易，§8 测量协议） | 赢家诅咒 + 相位 H-Z5 |

**A 臂匹配规程**（审查 §8.1 采纳、变量收缩防匹配失败）：对每个触发题材，在同日未触发的合格题材中做 k-NN（k=1）匹配，协变量 4 个——成分数、前 20 日题材收益、前 20 日成交份额、板块构成比例（主板占比）——标准化欧氏距离，卡尺 = 1.0 个标准差；无匹配 → 该事件退出 T−A 对比（记 `unmatched`，报告占比；占比 >30% 触发匹配规程失败警报）。**匹配含前期量价状态是刻意的：T−A 由此剥离"近期热度/动量"，孤立协调跃迁的净信息。**

## 6. 退出（主次翻转，恢复空退出教义）

- **主退出 = 固定期限**：20 交易日（主）+ 10 日（副），并 MUST 报告完整事件时间净超额曲线 CAR(1..60)——主判据 H-Z1/Z2/Z3/Z4 全部在固定期限口径上计算；
- **EXIT-3C 降为增强实验（H-Z6）**，精确化定义：
  - `Breadth(c,D)` = |{题材成分: close_qfq > MA20(close_qfq)}| / |可交易成分|（与既有广度公式同构，题材聚合）；
  - Leg A（EpisodeAge ≤10）：Breadth < 0.30 → 全退；Leg B1：CrowdPctl > 0.90 → 减半（一次）；Leg B2：Breadth ≤ Episode 内峰值 −0.20 ∧ 题材 RS20 < 0 → 余仓全退；Leg C：60 日兜底；优先级 A > B2 > B1 > C；
- V-STOP 变体沿用（个股相对题材 20 日超额 < −15%）；
- 卖出 D+1 收盘，跌停/停牌按 V11 §8A.4 顺延诚实建模；成本沿用（买 12.5bp / 卖 17.5bp，印花税 PIT），报告盈亏平衡摩擦点 x*。

## 8. 影子龙头测量协议（修正条件选择偏差）

对每个 Episode 的 MaxBoard 龙头，无条件（不分可买与否）记录四件套：
1. **机会收益**：假设理论价可得的 CAR(1/3/5/10/20)；
2. **可执行收益**：一字/T 字/换手板分类 + 开盘价可成交性判定下的实际可得收益；
3. **成交概率**：按板型与开盘状态的经验成交概率表（回测期实测统计，非假设）；
4. **相位检验（H-Z5）**：龙头与 ZJ 的事件时间 CAR 曲线并列——相位论成立的形态 = 龙头 CAR 集中于 EpisodeAge ≤ 3、ZJ CAR 集中于 5-15。（原"40% 不可买率"判据废除。）

## 9. 统计与功效

- 主推断：日历时间法（T 臂及 T−A 对比的日度序列，NW-t lag=10 + Block Bootstrap 5/10000），有效持仓日 ≥500；事件级 Bootstrap + Cohen's d ≥ 0.2；
- **聚类纪律（审查 §12.1 采纳）**：事件级推断按 (ConceptCluster × Episode) 聚类稳健；同簇重复事件不计独立样本；
- 触发频率闸门：DEV 年均 Episode 触发 ∉ [10, 150] → 停止上报（设计层问题）；
- 稳健性扫描（仅报告）：R-I1 ∈ {2.5, 3, 3.5}、R-C1 ∈ {3,4,5}、R-D1 ∈ {0,1,2}、容量下限 ±50%。

## 10. 基准（修正规模风格错配）

主判据 = **T−A 匹配对比**（自动风格中和）；辅助：① 规模匹配随机组合（同市值十分位随机股）；② 全 A 等权与沪深300 仅作经济参照系报告，不作判定基准。

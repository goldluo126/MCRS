## 1. 装置修复（R 系列，全部为 v2 前置条件）

### R1 数据修复与闸门强制化
- 提供有效 `TUSHARE_TOKEN`；拉取区间恢复 SPEC v1 要求的 **2013-06-01 ~ 2026-06-30** 全量并落盘缓存；
- G-DQ1~G-DQ4 四闸门全部重跑，**G-DQ3 必须以官方 `sw_daily` 通过**（板块价格与成交额主口径切换为官方指数，成分聚合仅作交叉验证）；
- **闸门代码级强制**：`data_layer.py` 中任一闸门失败 MUST `sys.exit(非零)` 并写 `GATE_FAILED.flag` 文件；下游脚本启动时检测该 flag 存在即拒绝运行。"失败后继续跑"从此在工程上不可能。

### R2 预热审计
- 每个板块每个交易日新增字段 `warmup_ok = (可用历史 ≥ 270 交易日)`（250 日分位窗 + 20 日均线）；
- `warmup_ok == False` 的 (板块, 日) MUST NOT 产生任何信号；
- DATA_AUDIT.md 新增预热审计表：各年份信号可用起始日、v1 的 45 个事件中落在预热受损区的数量（追溯审计）。

### R3 安慰剂升格为有效性闸门 G-PLACEBO（本修正案核心）
安慰剂从"检验项之一"升格为**解读任何真实结果的前置闸门**。顺序强制：修复数据 → 跑 G-PLACEBO → 通过后才允许查看真实信号结果（工程上：`run_event_study.py` 先输出安慰剂文件并断言通过，才解锁真实结果输出）。

三种安慰剂，全部要过：
1. **时移安慰剂**（沿用 v1）：信号后移 20 交易日，要求 |d| < 0.1；
2. **随机日期安慰剂**（沿用 v1）：牛熊比例匹配的随机日期，1000 次，真实值需落在零分布单侧 95 分位外（此条在 G-PLACEBO 阶段仅要求零分布本身居中对称、无机械漂移；对真实值的要求属结果判定）；
3. **同日随机板块安慰剂（新增，v2 关键诊断）**：保留每个真实事件的日期，把板块替换为当日未触发的随机板块，1000 次。作用：把信号拆解为"择时成分"与"选板成分"——若真实事件跑不赢同日随机板块，则信号全部价值来自日期（市场状态），横截面选板信息为零。

**G-PLACEBO 失败的处置**：停止读取真实结果，进入根因排查。排查清单（按先验概率排序）：① 事件时间聚集 + 板块动量自相关拖尾（诊断：事件日历分布图、事件后 20-60 日分段超额衰减曲线）；② 基准构造耦合（诊断：官方指数口径下重算，比较 v1 自建口径）；③ 对齐 off-by-one（诊断：§8 单测第 7 条扩展为对全部事件的自动断言）。**装置层修复允许迭代且逐条记录于 REPORT.md Decisions 节；信号层（C1-C5/P1-P18）在任何情况下禁止触碰。**

### R4 Level-2 条件跳过强制化

## 2. 统计功效重设计（S 系列，估计量升级，先验登记于查看修复后数据之前）

### S-R0 功效算术（v1 缺失的作业，此处补上并作为设计依据）
- v1 二值 LAUNCH 角点：45 事件、事件级 20 日超额 σ≈9.5% → 80% 功效最小可测效应 ≈4.0%/20日，不现实；测 d=0.2 需 150-200 事件，四维 AND 产率（≈6.5 事件/年）不可达。
- **结论：二值角点检验在本数据量下永远功效不足，主推断必须换估计量。**

### S-R1 主判据一：日历时间法（从 v1 的"并报法"升为主判据）
- 每日构造"活跃事件组合"（等权持有事件后 ≤20 交易日的板块），得日度超额收益序列（vs EW31）；
- Newey-West t（lag=10）+ Block Bootstrap（block=5, n=10000）；
- 样本量闸门更新：**有效持仓日 ≥ 500** 才可下 PASS/FAIL 判定，否则 INCONCLUSIVE；
- 该法用满全部持仓日信息、天然处理事件同日聚集，功效远高于事件角点。

### S-R2 主判据二：剂量反应面板（新增）
- 每周五截面，对全部 31 板块记录 `Score_{s,D} = 1{C1}+1{C2}+1{C3}+1{C4}` ∈ {0..4} 与未来 20 日超额收益；
- 检验单调性：Spearman 相关 + 按 Score 分组均值表 + 面板回归（周聚类标准误）；
- 先验预期写死：若四维论成立，超额收益应随 Score 单调上升且 Score=4 组最高；若仅拥挤度承重（H2' 情形），则单调性主要由 C1 驱动——两种形态都能被此设计区分；
- 面板观测数 ≈ 31 板块 × 350 周 ≈ 10000+，功效充足。

### S-R3 判定标准改写（替换 v1 §6 的 S1）
| 判定 | 条件 |
|---|---|
| **S1a 择时+选板综合** | 日历时间法日超额 NW-t 与 Bootstrap CI 同向显著为正（DEV），且 OOS 点估计同号 |
| **S1b 剂量反应** | Score 与 20 日超额 Spearman > 0 且 Bootstrap CI > 0，分组均值单调不减（允许一处平台） |
| **S1c 选板成分存在** | 真实事件组相对"同日随机板块安慰剂"零分布落在单侧 95 分位外 |
| S1 总判定 | a、b、c 至少两项 PASS 且无一项反向显著 |
- 二值 LAUNCH 角点（v1 口径）降级为描述性报告，保留可比性；
- S2（消融）、S3（拥挤警报）、S4（四维 vs 两维）保留 v1 定义，但消融改在剂量反应框架下同时报告（各维度对 Score-收益关系的边际贡献）；
- **新增 S6（H2' 重测）**：修复后的 DEV 上重测"C1 承重、C4 无贡献"是否复现；无论结果如何，**终审以 OOS 为准**。

## 3. 纪律边界（防 V3→V8 错误链复发，MUST 逐字遵守）

1. **信号定义与 P1-P18 零改动**。包括 T7 中符号翻转的 P7、包括 v1 消融显示"无贡献"的 C4。理由：v1 的全部 outcome data 来自故障装置，且即使装置无故障，依据 DEV 消融结果重构信号 = 用验证期数据反推策略（V12 教训 #2 原文）。
2. **H2'（拥挤度才是核心）的处理路径**：它此刻的身份是"从故障装置读出的、与独立先验方向一致的假设"。合法路径：v2 修复装置 → DEV 重测（S6）→ OOS 终审。若 OOS 确认，**再**起草 SPEC v3 围绕拥挤度重构复合信号（新 holdout、新登记）。非法路径：现在就改。
3. **本修正案自身的冻结**：S-R1/S-R2 估计量、S1a/b/c 判据、G-PLACEBO 通过线，在修复后数据的任何结果被查看之前冻结。此后任何变更 = v2.1 = 新试验。
4. 允许清单（穷举）：R1-R5 装置修复、G-PLACEBO 根因排查中的装置层代码修复、诊断图表增补。此外一切皆禁。

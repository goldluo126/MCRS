  真实历史年按奇偶分半 → 生成器开发年 / 生成器验证年
  合成年再对半 → α 校准合成年 / α 验证合成年

  预算: UCB_95(E[假确认触发/年]) ≤ 2 ∧ UCB_95(E[假资本占用日/年]) ≤ 40（协预算）
  UCB 主法 = t 上界（x̄ + t_{0.95,n−1}·s/√n）；稳健 = bootstrap 分位上界；半宽 ≤0.3 按 t 法
  选择规则 = 在 α 校准年上找出满足预算的候选集，取**最大 α**交 α 验证年独立复核；

## 8. 安慰剂（推断闭合）

- **P3/P4 双层重采样（修复伪 CI）**：外层 = 500 次对（canonical 簇 × 20 日时间块）联合 bootstrap；内层 = 每外层样本执行一轮伪化（P3 伪点火日 / P4 循环位移）；等效性判定用**外层分布**的 95% CI ⊂ [−0.1,+0.1]d ∧ [−10bp,+10bp]；
- **P4 活跃度匹配（修复平静期偏差）**：伪窗口全市场涨停数分位与真实窗口差 ≤ 1 个三分位；不满足重抽；某簇无合法位移 → 该轮剔除并记录（剔除率 >30% → P4 判不可执行并上报）；
- P1 = B 臂引擎（已去随机化，自检 = Gate0-Z）；P2 = 诊断。

## 9. 序贯法庭（分 estimand 边界世界）

- 双时钟修订（v9）：日历钟 = **自首个 Episode 起的全部非重叠 20 日块**（不设暴露率过滤——现金日是政策价值的组成部分）；事件钟 = 已锁定配对数；
- **分 estimand 边界世界（修复统一注入谬误）**：
  - 均值世界：处理侧 E[Δ]=10bp（同质 + 稀疏 20%×50bp 两情景，两者均值均为 10bp）；
  - 中位数世界：注入使 Median(Δ)=10bp 的对称位移情景（稀疏情景在此世界中位数为 0，不得用作中位数边界）；
  - 可投资世界：仅对容量子集注入 50bp；
  - 组合世界：Episode 流重排 + 完整账本重放，注入政策 spread 年化 1%；
  - 各 estimand 的 n_target 与序贯边界由**各自世界**校准；
- 终期 = 全部 Gate 主假设 n_target 最大值；未达自身 n_target 的假设判 INCONCLUSIVE；SMD 跳过机制、Gate3/4 无提前判决、封存-启封机制全部进仿真。

## 1. 核心命题与假设

**命题**（用户架构宣言的工程化）：题材（概念）是主力资金叙事共识的谢林点单元；协调证据（涨停梯队、席位集团化、杠杆承诺）能识别真题材的启动状态；真题材的**可交易 alpha 载体是中军**（机构谢林点），而非龙头（游资谢林点，赢家诅咒不可买）。过滤器确认的固有滞后（D+3~D+5）对龙头是迟到、对中军恰是相位匹配（机构资金 D+5~D+15 进场）。

| ID | 假设 | 证伪条件 |
|---|---|---|
| H-Z1 | 端到端（题材过滤 + 中军 + 退出，成本后）跑赢全 A 等权 | 日历时间净超额 CI 含 0 或 d<0.2；或影子运行不同向 |

## 2. 数据层：概念数据的 PIT 闸门（本版地基，用户特别指令）

### 2.0 两个陷阱的正式定义与偏差方向分析

**陷阱一：创设偏差（creation bias）**。概念指数常在题材炒起来之后才被创设（"低空经济"指数出现时行情已过半）。危害有二：① 概念的存在本身编码了"这个题材后来变大了"（幸存者信息）；② 创设前的回填行情由后见之明的成分构造。**偏差方向：对策略不利**——剔除创设前窗口会错过题材的首波最强段（策略只能交易题材的第二波及以后）。

**陷阱二：成分回填（membership backfill）**。`ths_member` 通常只提供当前成分，历史调入调出记录缺失或不可靠。用今天的成分切历史 = 把"后来在题材中证明了自己的股票"回填进历史聚合。**偏差方向：对策略有利**——历史上的概念聚合看起来比当时更协调、更强。

**两个偏差方向相反，净方向不可先验假定。**推论（MUST 写入一切报告的解读规则）：带 `member_backfill=true` 标签的区间上，**FAIL 是较强证据（有利偏差下仍失败），PASS 是弱证据（可能是偏差制造的）**。这就是为什么最终法庭必须是前瞻影子运行（§8）。

### 2.1 G-C1 创设闸门（陷阱一的处置）

- 拉取 `ths_index`（type='N' 概念）全表，记录每个概念的 `list_date`；
- **信号资格规则**：概念 c 在日 D 可参与信号计算，当且仅当 `list_date(c) + 60 交易日 ≤ D`（Q-U2 缓冲，让成分稳定并隔离"因行情而创设"的窗口）；
- **禁止使用任何 `list_date` 之前的回填行情/成分参与任何滚动窗口计算**；所有窗口起点 = max(list_date+1, 数据起点)；
- 诊断义务：报告"若无此规则本会触发"的事件数（被创设偏差规则排除的触发占比），量化本规则的代价；
- 概念退市/合并：沿用最后已知成分至持仓自然退出，新信号停止。

### 2.2 G-C2 成分快照闸门（陷阱二的处置，两段式）

**第一段：快照普查（先于一切开发）**。验证 Agent MUST 盘点 Tushare 全部概念成分源的历史快照可得性：`ths_member`（是否有可靠 in/out 日期）、东方财富板块（`dc_member`，是否支持按 trade_date 查历史快照及其起始日期）、开盘啦题材库（`kpl_concept_cons`，同上）。产出 `CONCEPT_DATA_CENSUS.md`：各源的最早快照日期、快照频率、概念覆盖数、与 ths 概念的映射可行性。

**第二段：先验决策规则（现在冻结，普查结果出来后机械执行，不得临场发明）**：

| 普查结果 | 处置 |
|---|---|
| 存在带日期快照、覆盖 ≥3 年且含牛熊 | 该覆盖窗为 DEV，快照口径为唯一成分真相源 |
| 快照仅覆盖近期（<3 年） | 快照覆盖段为 DEV（短而干净优于长而脏）；更早区间**禁止用于任何判定**，最多作 `member_backfill=true` 的方向性参考 |
| 完全无历史快照 | DEV 全程标 `member_backfill=true`，降级为管道调试 + 方向性参考；判决权完全移交影子运行 |

**第三段：自建 PIT 快照库（无条件执行）**。自登记日起，每个交易日收盘后快照 `ths_member`（及可得的 dc/kpl 源）入库（append-only，含拉取时间戳）——这是影子运行的成分真相源，也是留给未来一切概念研究的地基资产。

**第四段（v2.1 增补）：主源选定规则与三源一致度诊断**。
- **单一主源原则**：题材单元由一个主源定义，MUST NOT 三源合并造本体（合并 = 无穷编辑自由度）。其余源仅作交叉验证与诊断；
- **主源选定判据（按优先级，普查实测后机械触发）**：① PIT 快照可得性（硬门槛）；② 时段覆盖（DEV + 影子期）；③ 语义匹配（叙事标注 > 分类学；预判：KPL 快照历史足够 → KPL 主源；不足 → THS 主源 + KPL 影子期增强；DC 永远作交叉验证）；
- **三源映射与一致度诊断（普查交付物）**：名称模糊匹配映射表 + 同题材成分 Jaccard 矩阵 + 各源独有题材清单；
- **谢林收敛度指标（诊断，本轮不进过滤条件）**：触发题材的跨源核心成分交集比例。理论依据：谢林点的定义即无协调收敛——真题材应表现为三源不约而同收录且核心成分高度重合；三源各说各话的"概念"疑为编辑构造。该指标作为题材纯度的伴随测量记录于每个事件，未来晋升为过滤维度须走新登记；
- **成分误差敏感性口径**：主结果之外，对触发题材以"主源成分 ∩ 至少一个其他源"的核心交集重跑 T 臂（敏感性检验，非主口径）。中军载体（市值前 1/3 × 成交额前 2）对边缘成分分歧天然低敏感，此敏感性检验预期差异有限，若差异大则本身是警报。

### 2.3 G-C3 概念宇宙治理

- 成分数边界：8 ≤ n ≤ 100（Q-U3；过小无广度语义，过大是准指数）；
- **机械/风格概念排除表**（冻结名单，按名称模式）：含"融资融券|沪股通|深股通|MSCI|富时|标普|中证|上证|深证|创业板综|科创50|次新股|破净|预增|预亏|ST|昨日涨停|昨日连板"等非题材性概念。Agent 应用后输出完整排除清单，**开跑前**交人类目检一次（此时尚无任何结果，目检合法）；
- **同日重叠去重**：两概念同日触发且成分 Jaccard > 0.5 → 只保留 LU 数更高者（Q-U5），记 `merged_trigger`。

### 2.4 G-C4 交叉校验与既有闸门继承

## 3. 协调证据过滤器（精确定义与冻结参数）

对每个合格概念 c（过 G-C1/C3），交易日 D 收盘后计算（全部用 ≤D 数据；两融用 ≤D-1）：

### 3.1 维度定义

```
F1 涨停梯队（情绪协调的直接观测）:
   LU_{c,D}        = |{i ∈ 成分(c,D): close_raw ≥ up_limit}|          # 收盘封板数
   MaxBoard_{c,D}  = max 成分连续涨停天数
   BombRate_{c,D}  = |{触板未封: high_raw ≥ up_limit ∧ close_raw < up_limit}| / |{触板}|
   F1 = (LU ≥ 3) ∧ (MaxBoard ≥ 2) ∧ (BombRate ≤ 0.5)                 # Q-F1a/b/c

F3 席位集团化（游资集团作战的显影）:
   SeatBreadth_{c,D} = [D-4,D] 内登上龙虎榜且净买入>0 的不同成分股数（top_list）
   F3 = SeatBreadth ≥ 2                                               # Q-F3

F4 叙事持续性（剔除一日游）:
   F4 = ( LU_{c,t} ≥ 2 对最近 5 日中 ≥ 3 日成立 )                     # Q-F4

F5 拥挤否决（唯一幸存的方向性证据，仅作 veto 不作条件）:
   CrowdPctl_{c,D} = 概念成交额占全市场份额（20日平滑）在自身 ≥120 日历史中的分位
   VETO = CrowdPctl > 0.90                                            # Q-F5；历史<120日 → 不否决，标 crowd_short_history

F2 杠杆承诺（登记为副臂增强，不进主过滤器）:
   MarginAccel_{c,D} = Σ成分融资余额_{D-1} / mean(Σ成分融资余额_{D-21:D-2})
   F2 = MarginAccel ≥ 1.05                                            # Q-F2
```

### 3.2 触发定义（吸取 SL-4D 倒 U 教训：AND 深度压到 3）

```
TRIGGER_{c,D} = F1 ∧ F3 ∧ F4 ∧ (NOT VETO)      # 主定义
TRIGGER+      = TRIGGER ∧ F2                    # 副臂（杠杆增强版，对照报告）
```
- 事件去重：同概念 20 交易日（Q-T）；跨概念同日去重按 §2.3；
- **设计理由留痕**：SL-4D 剂量反应显示确认深度 4 的角点最差（−1.28%）——本过滤器主定义刻意停在三条件，F2 只做副臂、F5 只做否决，防止过度确认吃光中段。

## 4. 中军选择规则（alpha 载体）

对触发概念 c，D 日收盘后：

```
候选池: 成分(c,D) ∩ 可交易(非停牌/非ST/非退市整理)
       ∩ 自由流通市值位于概念内前 1/3                                  # Q-Z2
中军分: 按 [D-4,D] 五日成交额合计降序                                  # Q-Z3
选取:   前 2 名为 Z1/Z2                                               # Q-Z1
可买性: D+1 开盘涨停或停牌者剔除，顺位替补至成交额第 4 名               # Q-Z4
       仍不足则少买；记 dropped_zj 诊断
入场:   D+1 开盘价（open_raw）；副口径 D+1 VWAP 并报
权重:   每事件 Z1/Z2 各 1/2 事件资金；组合并发上限 6 个事件（12 只）    # Q-E
```

**影子龙头臂（不交易，纯测量）**：每个触发事件同时记录 MaxBoard 龙头股的假想路径——D+1 开盘可买否（涨停判定）、若可买其 20 日净超额、若不可买记 `leader_unfillable`。用途：① 直接测量赢家诅咒（H-Z5）；② 检验相位错配论（龙头 vs 中军的入场可行率与后续收益对比）。

## 6. 退出与成本

- **主退出 EXIT-3C（概念级状态变量适配）**：Leg A 失败确认（进场 ≤10 日内概念广度 Breadth_c < 0.30 → 全退）；Leg B1 高潮减仓（CrowdPctl_c > 0.90 → 减半，仅一次）；Leg B2 顶部确认（Breadth_c ≤ 进场后峰值 −0.20 ∧ 概念 RS20 < 0 → 余仓全退）；Leg C 满 60 交易日兜底。优先级 A > B2 > B1 > C；
- **空退出对照**：固定 20 交易日（EXIT-3C 必须净胜之，H-Z6）；
- **V-STOP 变体**：附加个股安全腿（个股相对概念 20 日超额 < −15% → 单股退出）；
- 卖出 D+1 收盘价，跌停/停牌按 V11 §8A.4 顺延（滞留期诚实计入）；
- 成本：买 12.5bp / 卖 17.5bp（印花税 PIT，2023-08-28 前 10bp）；毛/净并报 + 盈亏平衡摩擦点 x*。

## 7. 统计、功效与安慰剂

- **主推断**：日历时间法（T 臂日净超额 vs 全 A 等权，NW-t lag=10 + Block Bootstrap 5/10000），有效持仓日 ≥500；
- 事件级：20 日净超额 Bootstrap CI + Cohen's d ≥ 0.2；功效闸门：DEV 个股级事件 ≥100，不足则事件级降为描述性；
- **G-PLACEBO-Z（解锁真实结果的前置闸门）**：① 时移 +20 日全管道 |d|<0.1；② 同日随机概念（A 臂机器）零分布居中；③ 同概念随机成员（B 臂机器）零分布居中；
- 稳健性扫描（仅报告）：Q-F1a∈{2,3,4}、Q-F1b∈{1,2,3}、Q-F3∈{1,2,3}、Q-F4∈{2/5, 3/5, 4/5}、Q-Z1∈{1,2,3}；
- 触发频率普查先行：若 DEV 年均触发 >150（过滤器过松成噪声）或 <10（过紧无功效），停止上报——阈值口径问题属设计层。

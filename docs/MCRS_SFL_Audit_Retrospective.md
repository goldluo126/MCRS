## §1 问题分类学（8 类 × 4 严重度）

| 类别 | 定义 | 典型 |
|---|---|---|
| **T 理论/语义** | 命题本身或其措辞错误：测量对象与声称对象不符 | 状态 vs 跃迁；选择器 vs 过滤器；"启动"vs"相变" |
| **I 因果识别** | 估计量不识别声称的因果对象：污染、选择、条件化错误 | 法庭 ZJ 污染；处理后匹配；immortal-time；未来筛选 |
| **S 统计校准与推断** | 错误率、功效、多重性、序贯、零模型的数学缺陷 | PB 独立性；maxT 循环；经济 PASS 无家族；α_spent 记账 |
| **D 数据生成过程/PIT** | 校准世界与真实世界错配；时点与可得性 | 供应商本体 ≠ live 过程；trade_date≠as-of；时钟 PIT |
| **U 算法唯一性/可编译性** | 两个合规实现会产生不同正式输出 | 秩矩阵、tie-break、聚类顺序、家族定义、单位 |
| **M 实现级/数学错误** | 可被反例直接证伪的算术/组合/逻辑错误 | D0+10 算术；池=5 抽 200；HK≠完美置换；恒等退化 |
| **E 经济/执行现实性** | 资金尺度、容量、清算、账本与市场制度 | 名义 1 单位；隐性杠杆；一字判定；haircut 无流动性依据 |
| **G 治理/文档/生命周期** | 预承诺、终止规则、版本回归、重试通道 | canonical 回引 ×4；regime 无限重试；冻结顺序污染 |

严重度：**致命**（直接使正式判词/实验无效）｜**高**（改变样本、错误率或可编译性）｜**中**（功效/保守性/诊断）｜**低**（措辞/优化建议，宪法后归登记簿）。

## §6 深度洞见

**洞见一：缺陷类别的单调下沉是收敛的形态学，不是失败的证据。** 十五轮的缺陷主类从理论→识别→统计→算法→实现→治理逐层下沉，且上层类别几乎不复发（理论层自 R1 后零新增致命项）。复杂协议的正确性不是一次性获得的，是按抽象层级逐层证伪出来的。评估一个规格的成熟度，看的不是"还有没有问题"，而是"当前问题位于哪一层"。

**洞见二：零驳回率的正确解读。** 440 条论点 100% 成立不说明审查方全知，而说明两件事：初版规格在每个抽象层都携带该层的典型错误（这是先验可预期的）；以及**对抗性审查在被审对象诚实配合时的命中率可以极高**——我从未为省事而辩护，审查方从未为存在感而挑刺，宪法出现前的十三轮里双方共享同一个目标函数。这种关系本身是方法论资产。

**洞见三：确认有价格，且价格可以吃光全部商品。** 从 SL-4D 剂量反应倒 U（四重确认角点 −1.28%）到 SFL 把 AND 深度压到 3、确认改 landmark、E3 双口径计量延迟成本——整个项目最贵的一课是：**每一层确认都用滞后购买精度，而市场支付给确认后入场者的中段是有限的**。协议设计中的每个"再等等、再验证一次"都必须进同一张会计表。

**洞见四：零模型的灵魂是反事实定义，不是计算精度。** "对错误零模型做精确动态规划，只会得到非常精确的错误概率"（R3）。PB 独立性、只换涨停标签、donor 同题材互换、逐日置换毁掉连板——四次零模型返工的共同教训：先用一句话写清"保留什么、消除什么"，再谈算法。

**洞见五：测量仪器是模型的一部分。** 供应商题材本体不是数据输入，是一台会漂移、会因行情而重构自身的测量仪器。由此推出三件事：校准世界与终审世界必须经 live null replay 桥接；本体漂移可能与最强信号相关（信息性删失必须写进判词）；"条件于供应商本体"是永久识别边界而非可修复缺陷。

**洞见六：时间信息不可由重复采样制造。** 60 日本体 ×200 次重放只消除 Monte Carlo 误差；数十万股票-日行在 Wilson 区间下假装精确而独立时间块只有 3 个。凡涉及市场的精度声明，分母必须是独立时间结构，不是行数或重复数。

**洞见七：错误预算必须打到资本层。** 假点火→假确认→假可投资→假成交→假资本占用日的漏斗中，真正伤害资本的是最后一层。E[FalseCapitalDays] 比任何信号层错误率都更接近项目风险——错误预算的锚应设在钱上。

**洞见八：统计拒绝与业务通过是两个状态机，必须显式合并。** 收益显著但回撤失败的节点不能向下游输血；经济 PASS（θ>MES）与统计阳性（θ>0）是两个假设家族——只控制后者保护不了前者。full-pass = 统计拒绝 ∧ 护栏，是把两台状态机焊成一台的最小代价方案。

**洞见九：严格 ≠ 有信息；协议的头号死因从假阳性变为"永远 INCONCLUSIVE"。** 每加一道闸门（Gate0、匹配、SMD、状态覆盖、drift、审计、前瞻数据）都消耗有效样本。成熟协议的 OC 核心指标不是 Type-I/power，而是 **P(在 3/5/8 年内达成任何判决)**。错误控制与可判定性之间的平衡必须预登记，否则完美协议 = 永不开庭的协议。

**洞见十：审查本身需要宪法，否则审查成为最体面的逃避证伪方式。** 无限深挖模式下，任何复杂系统都可以被永远"再改进一轮"——对设计方是拖延，对审查方是安全区。终止规则（A=0∧B=0 即合格）+ 反例准入门槛（分歧反例/预算超限反例/对象错配反例）把审查从品味之争变成可判定程序。这条宪法本身，可能是十五轮中最可迁移的产出。

**洞见十一：文字审查有边际递减点，代码是更便宜的下层审查介质。** R7 之后的实现级错误（算术、组合数、一字判定）在任何合格工程师写单测时会当场暴露；但 R9-R13 证明统计与治理层的错误文字审查仍然更快。正确分工：理论/识别/统计/治理归文字审查，算法唯一性/实现级归双实现哈希对拍——v13 §16 的验收协议正是这个分工的制度化。

**洞见十二：留痕比正确更稀缺。** 十五轮、27 处自认错误、每处的反例与修复路径全部可追溯——这个项目最终的可信度不来自"不再有错"，而来自**每个错误都有编号、每个判词都有预算、每次失败都有归因路径**。对一个以证伪为业的系统，错误处理的透明度就是它的资产负债表。

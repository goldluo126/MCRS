## 3. 零模型与状态机（v6 核心修订）

### 3.1 标准 Westfall-Young maxT（修复循环定义）

```
原始统计量（学生化）:
  T_c,D = ( LU_c,D − μ_perm(c,D) ) / ( σ_perm(c,D) + 1e-9 )
    μ_perm/σ_perm = 该题材在 B 次同日分层置换下 LU 的均值/标准差
流程:
  对第 b 次置换: 计算全部休眠题材的 T_c,b；记 M_b = max_c T_c,b
  族校准 p 值: p_FWER(c,D) = (1 + #{ M_b ≥ T_obs_c }) / (B + 1)
点火: LU_real ≥ 2  ∧  p_FWER ≤ α_day
```
- **α_day 由假 Episode 预算反推（冻结）**：全局零假设下年度假 Episode 预算 **≤2 个/年**（含冷却去重效应，由仿真验证）⇒ α_day ≈ 0.8%（仿真校准后冻结精确值；预算 ≤1 与 ≤5 档进敏感性扫描）；
- **Monte Carlo 纪律**：常规 B=2000；候选题材 p_FWER 落在 [α_day/3, 3α_day] 临界带时自适应升 B ≥ 20000；对经验 p 计算 Clopper-Pearson 上界，**上界 ≤ α_day 才点火**；seed = hash(trade_date, source_version, spec_version)；
- **种子稳定性闸门**：临界候选换 5 个独立种子重跑，≥4 次通过才点火，否则标 `permutation_unstable`（数值稳定性检查，非调参）；
- **分层诊断义务**：日有效层数、中位层规模、粗化发生率、题材成员所在层有效样本量，全量入库。

### 3.2 行业条件双口径（v6 新增，命题 B 立场）

- 本实验的科学命题冻结为**命题 B**：题材是跨行业的原生协调单元；
- 每个点火事件 MUST 同时计算：`ThemeShock`（§3.1 主口径）与 `ThemeShock|Industry`（置换分层加入申万一级行业 × 市值三分位，其余维度粗化）；
- 事件标签：条件口径不显著（p>0.10）→ `industry_driven`；
- **解释规则（冻结）**：H-Z2a 分"全部事件"与"跨行业子集（非 industry_driven）"双报告；若仅全部事件口径有效而跨行业子集无效 → 结论 MUST 写"题材标签主要承载行业共同冲击，跨行业协调假设未获支持"。

## 5. 法庭

### 5.1 第一法庭（沿 v5 双 estimand + v6 修订三处）
- **匹配平衡（修复不可执行规则）**：按登记算法一次生成全部配对 → 整体 SMD 检查 → 任一审计协变量 |SMD|>0.10 即 `MATCH_BALANCE_FAILED`（整体失败，人工裁决后只能作为新版本重新登记匹配算法）；**禁止迭代删对**；附加登记约束：T-A 成分 Jaccard < 0.2、单控制复用 ≤3（频数权重）、处理与控制组合的个股重叠率上限 20%；

### 9.4 冻结前盲化样本量估计（v6 更名与修订，废除"未触真实收益"声明）
- 专用脚本以盲化模式访问 DEV：**仅输出** pooled 方差、簇内相关、事件频率、n_target 与信息量刻度；**禁止输出**任何组均值、差值方向、分组效应（代码审计断言）；
- 保守情景兜底：并行给出悲观方差/ICC 情景下的 n_target，取二者较大者冻结；
- 本步骤的诚实名称：**冻结前盲化样本量估计**（blinded sample-size determination），不再声称"未访问真实结果"。

### 9.5 序贯边界（v6 修订，废除直接套用 OBF）
- 边界由**完整分析管道仿真**校准：在 θ=MES 边界情形生成保留真实事件频率、控制复用、簇内相关与日期重叠的合成路径，于信息比例 1/3、2/3、终期运行与正式分析完全相同的匹配+bootstrap 流程，校准总体错误率后冻结数值边界；
- **中期分析按信息比例 I_k/I_max 触发**（以配对差值估计量的逆方差度量），非名义 Episode 数；
- 提前判决仅允许 Economically PASS；提前"FAIL"仅为 non-binding futility；正式 FAIL 只在终期。

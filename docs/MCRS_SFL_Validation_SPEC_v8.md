- **确定性聚类算法（冻结，修复 clique 不唯一）**：
```
输入: 当日合格题材集，Members_{D−1}
1. 计算全部题材对 Jaccard；候选对 = J>0.5，按 (J 降序, 题材ID对字典序) 排序
2. 顺序处理候选对 (x,y):
   x,y 均未入簇 → 建新簇 {x,y}
   一方在簇 S → 当且仅当另一方与 S 全体成员 J>0.5 时并入（clique 校验）
   双方在不同簇 S1,S2 → 当且仅当 S1∪S2 任意两两 J>0.5 时合并
   其余情形跳过
3. 未入簇题材各自单簇
```

## 3. 日度零模型（minP，秩矩阵唯一化）

```
分层: 板块 × 市值3 × 波动3 × 动量3 × 股性3；层 ≥8；粗化序 动量→波动→股性→市值；板块永不合并
置换: 保留当日各层真实涨停数，层内重排标签；B_random 条随机置换 + 观测配置 = B+1 行
统计量矩阵（(B+1)×C，b=0 为观测行）: S[b,c] = LU_{c,b}（题材涨停计数）
边际 p（对每行 b、每题材 c，在全部 B+1 行内取秩）:
  p[b,c] = #{ b' ∈ {0..B} : S[b',c] ≥ S[b,c] } / (B+1)      # 含自身，≥ 计并列
p_marg(c,D) = p[0,c]（Monte Carlo permutation tail probability——禁称"精确"）
m_b = min_c p[b,c]（b = 1..B，仅随机行）
p_FWER(c,D) = (1 + #{ b ∈ 1..B : m_b ≤ p[0,c] }) / (B_random + 1)
CoordinationState(c,D) = −log10( p_marg(c,D) )（全部合格题材每日算，专用于休眠历史）
点火: LU_real ≥ 2 ∧ p_FWER ≤ α_day
两阶段（冻结）: 全族先 B_random=2000；当日任一候选 p̂_FWER ∈ [α_day/3, 3α_day]
  → **当日全部休眠题材统一**升 B_random=20000 重算（不得只重算临界者）
seed = hash(trade_date, source_version, spec_version)
```
- 证据边界措辞：严格校准全局零假设下的日度扫描错误；事件级强 FWER 仅近似；
- 行业条件口径与三态标签沿前版（p_cond≤0.10 supported / not_supported / uninformative）。

```
  事件内标的等权；同股冲突先到先得后到留现金；单股总权重 ≤2×单事件单股预算；现金收益 0；
  同日冲突优先级 = **题材 ID 字典序**（p 值仅作资格，不排资本——废除稀有度→alpha 隐含假设）；
  无抢占；拒绝不补入；空池即时释放
判决（H-P1a 主）: CI_lower[年化R(C)−年化R(I)] > 1%（stationary bootstrap 块 20）
  护栏: MDD 差 ≤2pp ∧ CVaR 不劣（点估计）；双口径必报（资本口径 + 投入调整口径）
H-P1b/M-I/M-C/DiD 描述性沿前版
```

### 7.3 第三法庭（执行时钟封口）
Leg 判定于 D 收盘 → 执行 D+1 VWAP（5% 参与+顺延滚动）；Breadth 峰值自入场日 D0+5 起计；60 日兜底自入场日起第 60 个交易日；同日多腿按 A>B2>B1>C 取一执行、其余记录；与固定退出的对比 = 同一入场流完整组合模拟（资本占用/挤出/换手内生），**H-Z6 推断块长 = 60 日**（匹配其最长持仓依赖）。

### 7.4 第四法庭（执行公式与基准封口）
- 成交（修复一字判定）：**买入零成交 iff high==low==涨停价；卖出零成交 iff high==low==跌停价**；其余日 Fill = min(Order, 5%×当日成交额)，同股订单先合并再检查；卖出未完逐日滚动、剩余仓位继续计收益；VWAP = amount×10/vol；滑点 = Decision-to-VWAP slippage；容量情景 1/3/5%；
- 动态暴露基准（定义封口）：Exposure_t = 日初持仓市值/日初 NAV（前收盘口径，净=总，无空头）；R_dyn = Exposure×R_capacity + (1−Exposure)×R_cash(=0)；capacity 指数 = 全 A 容量可交易等权、月末最后交易日定成分、次月首交易日 VWAP 调仓、月内退市/停牌持有至可交易、与策略同一成本模型、毛/净双口径；
- 判决量更名 **年化净超额收益**（CAGR 差口径；未做风格调整故禁称 alpha），MES=3%。

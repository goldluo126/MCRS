## 0. 问题原文（用户提出）

**第一组问题**（针对论断"合理的工程目标是：在行情前段完成确认、放弃底部、赚中段——然后诚实检验中段减去成本还剩多少"）：
1. 如何完成"行情前段确认"？用什么核心指标来确认？
2. 如何诚实检验中段减去成本还剩多少？如何具体操作？
3. 详细解释上述工程目标的底层逻辑。

**第二组问题**（用户对框架的提炼与追问）：
> 1. "板块启动"不可得。
> 2. "板块启动"确认可得，但有价格。
> 3. "诚实的检查中段减去成本还剩多少"就是 alpha。但这就涉及到另外两个问题：**什么时候退出？退出的逻辑是什么？** 没有退出就算不出中段是多少。退出 − 进入 = 中段，alpha = 中段 − cost。

## 1. 总纲：三个承认

这个工程目标是三个承认的叠加：

1. **承认拐点不可预测** → 所以做确认，不做预测；
2. **承认确认有价格** → 所以放弃底部（前段是保费）；
3. **承认剩余可能为零** → 所以诚实检验（会计机器防止把"没有肉"雕成"有肉"）。

三个承认合起来，把一个浪漫的问题（"如何抓住板块启动"）改写成一个会计问题（"确认滞后之后、摩擦和逆向选择之前，市场还愿意留下多少钱"）。会计问题的好处：它有答案，且答案不由愿望决定。

### 1.1 为什么拐点不可预测（因果结构）

板块底部由尚未公开的信息形成（政策酝酿、产业资本布局、机构建仓）。这些信息进入价格之前，不存在于任何公开量价数据中；而量价是已发生交易的函数，只能**记录**转变，不能**先于**转变。凡回测中显示"精准预测拐点"的量价指标，要么是过拟合噪声，要么是被错误标注的确认器。承认这一点 = 一次问题替换：从"拐点何时出现"（不可回答）换成"转变的扩散是否已开始、开始后是否有可利用的延续性"（可回答、可证伪）。

### 1.2 放弃底部是买入更好的条件分布（保费逻辑）

无确认的"疑似底部"是一个宽的、负偏的结果分布（多数疑似底部是下跌中继）。确认后再买，买到的是条件分布：均值更高、左尾更薄。两个分布的差价 = 放弃的前 10-20% = 保费。趋势跟踪的长期存活证明这个结构可以为正——但那是别的市场的证据，A 股板块层面是否成立是本实验的开放问题，不能引用别人的鱼身证明自己碗里有鱼。

### 1.3 为什么"诚实"是承重词

中段 = 全段 − 前段（保费）− 尾段（退出滞后），再减摩擦、逆向选择、摊假阳性——每项都是减法，剩余即使为正也是小效应。**小效应恰是 p-hacking 最易凭空制造之物**（换退出规则、剔"异常"事件、挑成本假设即可雕出不存在的中段）。先验登记、全事件会计、盈亏平衡点、双假设夹逼、OOS 锁箱这套机器存在的唯一理由：当市场说"没有"时，我们听得见。

## 2. 前段确认：如何做、用什么指标

### 2.1 "前段"的操作化定义（先可测量，才可讨论）

- **事后行情段**（仅作诊断标尺，禁入交易规则）：板块相对等权基准超额净值，波谷→波峰 ≥X%、持续 ≥Y 日的一段，波谷记 0%、波峰记 100%；
- **确认质量三度量**：
  - 入场位置分位：信号可执行时点（D+1）已走完该段的百分比；"前段确认"的可证伪含义 = 中位数 ≤ 20-30%；
  - 捕获率：信号后至退出吃到的涨幅 ÷ 全段涨幅；
  - 精确率：全部触发中事后对应合格行情段的比例。
- 三者构成"启动定位审计"（验证报告的诊断附件；只准用于评估信号落点，禁止反向用事后行情筛选样本——那是条件在成功上）。

### 2.2 确认指标的自然时序栈

A 股板块启动的可观测痕迹有生理时序（事件时间，D0 = 点火日）：

```
D0        龙头首板（涨停结构：最早、噪声最大）
D1-D3     量比抬升并持续（资金先于价格大幅变动）+ 首板→二板晋级
D3-D5     广度跳变（站上 MA20 占比从低位跳升：从"个股事件"变"板块行情"的定义性证据）
D5-D8     RS 由负转正 / 60 日新高（价格穿越：最迟、假阳性最低）
```

| 指标 | 典型确认滞后 | 假阳性率 | 角色 |
|---|---|---|---|
| 涨停结构 | 最短 | 最高 | 事件哨兵，须配低拥挤 |
| 量能自体扩张 | 短 | 高 | 最早非价格痕迹；持续性要求 = 用滞后换信噪比 |
| 广度跳变 | 中 | 中 | 定义性证据（板块在动，非单一权重股） |
| 价格穿越 | 长 | 低 | 终审确认，吃掉前段最多 |
| 低拥挤（份额分位） | 非时序 | — | 前提条件：同样量价形态在高分位区是高潮不是前段 |

### 2.3 核心洞察：早与准是同一条曲线的两个方向

不存在"最早又最准"的指标。确认设计的自由度不在发明新指标，而在选择 ROC 曲线上的驻点：全维 AND = 晚而准；任一 OR = 早而滥；计分制（SPEC v2 的 Score 0-4 剂量反应）= 把整条曲线测出来，让数据报出"每往早挪一档付多少假阳性"的价格表。

纪律：驻点（阈值/持续天数）由先验 + 稳健性扫描决定，禁止由回测收益优化决定——用收益选驻点 = 验证期数据替你挑参数 = 中段被虚增。

## 3. 诚实会计：中段减成本的具体操作

每事件净期望恒等式：

中段捕获（D+1 入场 → 规则退出） − 往返摩擦 − 逆向选择拖累 − 假阳性损失（内含于全事件均值）

五条会计规则，每条堵一个作假通道：

1. **分母是全部触发事件**，不是成功事件。任何"剔除异常""只统计有效启动"= 条件在成功上，立即作废；
2. **中段两端先验冻结**：入场端由确认规则、退出端由登记的退出规则；在同一数据上优化退出 = 事后画大中段；
3. **逆向选择要测量不要假设**：信号最强时刻恰是龙头涨停锁死时刻，指数收益里最肥的部分是买不到的部分。测法（Level-2.5）：同组事件跑两遍——指数价入场 vs 仅用 D+1 未涨停非停牌成分的可买组合入场，两条净值之差 = 逆向选择的实测价格；
4. **报告盈亏平衡摩擦点 x\***（使全事件净期望归零的单边摩擦水平），而非只报某一成本假设下的净收益。x\* 直接暴露安全边际；配套成本 +50% 压力测试与双成交假设夹逼，单一假设下才存活的结果判不稳健；
5. **中段是时变原材料，按年报告存量**：A 股轮动加速（高低切）可能使合格行情段逐年缩短；若近年剩余中段系统性短于早年，结论必须写明"该策略赖以生存的市场结构正在消失"。

## 4. 退出：中段的另一端（针对第二组问题 3a）

用户恒等式：退出 − 进入 = 中段，alpha = 中段 − cost。其深层推论：**进场规则冻结后，全部优化压力（以及全部 p-hacking 诱惑）都落在退出上。**

### 4.1 退出为什么比进场更难：三个结构性原因

1. **信息结构更差**。进场时站在干净的先验基态（低拥挤、低波动）上等一个清晰跃迁，对比度高；退出时身处高波动的行情中段，要区分"顶部"与"中继回调"——两者短期量价形态几乎相同（都是量缩价跌）。底部跃迁有自然的指标时序栈，顶部没有对称结构——**唯一有结构性逻辑的顶部指标是拥挤度**：成交额份额是零和约束下的比值，冲到自身历史极值在数学上不可持续。这正是"天量天价"直觉的正确位置。
2. **执行不对称**。T+1 + 跌停制度使卖出在最需要时最难执行（退潮期跌停顺延、流动性坍缩）→ 回测中的止损价值被系统性虚高；印花税单边征于卖方 → 退出摩擦本身高于进场。（与 V11 NDP 买卖侧阈值不对称 0.85/0.90 同一物理来源。）
3. **自由度诅咒**。进场只回答"何时开始"；退出要同时回答何时、是否分批、盈亏是否对称——参数空间是进场的数倍。回测中几乎所有"策略改进"实际来自退出调优，这是过拟合最肥沃的土壤。

### 4.2 退出规则分类学

| 类型 | 逻辑 | 失效模式 |
|---|---|---|
| 时间退出（固定 k 日） | 中段有特征长度，固定窗口匹配信号衰减半衰期 | 状态盲：中途卖飞真行情、满期持有假启动 |
| 信号死亡退出 | 进场论点是状态，状态消失（广度回落/量能塌缩）则论点消失 | 参数翻倍 + 需滞回设计，过拟合风险翻倍 |
| 对手信号退出 | 启动与高潮是两个状态，用高潮检测器（ALARM：份额分位 >0.90）退出 | 高潮不一定来——很多中段直接阴跌退潮，ALARM 永不触发 |
| 失败退出（止损） | 假启动动力学 ≠ 真启动暂歇，早砍假阳性直接改善全事件期望 | A 股现实：需要止损时常是跌停卖不出，回测价值虚高 |
| 移动止盈 | 锁定已实现涨幅 | 参数最多，对高波动中段 whipsaw 最敏感 |

### 4.3 洞见一：固定持有期是"空退出"（null exit）基线

固定 k 日退出看似最笨，但有三个无可替代的性质：**零状态参数**（只有 k，可先验冻结）；**统计干净**（策略的"中段"与事件研究的"k 日前瞻超额"完全同一——回测即测量，零额外自由度）；**免疫 whipsaw**。

因此它是空退出基线，与"等权全板块是基准"同构：任何聪明退出（ALARM 提前退、信号死亡退、止损）必须在**全事件净期望**上净胜固定 k，且胜幅付得起新增参数的过拟合风险溢价。SPEC 的 P1（固定 20 日）为主、P1b（ALARM 提前退出）为对照的裁决结构即此：P1b 胜出且左尾（CVaR）改善 → ALARM 退出挣到了它的复杂度；否则笨办法当立。

### 4.4 洞见二：中段是（市场 × 退出规则）的联合属性；期限结构是市场的报价单

同一段行情，不同退出规则切出不同中段。"中段有多少"必须拆成两问：

1. **市场在各持有期限上开价多少**：E[excess(k)]，k = 5/10/20/60——T1 事件研究测四个期限的真实原因：它们描绘信号的衰减曲线（中段的期限结构），即市场对"确认后持有 k 天"的报价单；
2. **特定退出规则从报价里收割多少**：Level-2 的职责。

报价单的用法：曲线走平处 = 平均中段的终点；固定 k 的最优邻域 = 边际超额 E[excess(k+1)] − E[excess(k)] 降到边际持有成本（摩擦摊销 + 机会成本）以下的位置。聪明退出的本质是估计**条件**版本的曲线（E[剩余超额 | 当前状态]），它们通常失败——条件估计的方差吃掉条件信息的均值。

纪律：从 DEV 期限结构读出 k 的合理邻域是测量（允许）；k 冻结后由 OOS 检验；逐段行情调 k = 把退出变成拟合（禁止）。

### 4.5 洞见三：完整的 alpha 恒等式（规则条件版）

$$\alpha_{\text{rule}} = \mathbb{E}_{\text{全事件}}\!\left[\left(\tfrac{P_{\text{exit}}}{P_{\text{entry}}}-1\right)-\left(\tfrac{B_{\text{exit}}}{B_{\text{entry}}}-1\right)\right] - f_{\text{round-trip}} - \delta_{\text{adverse}}$$

- B = 等权全板块基准同期净值（机会成本内建于恒等式）；
- 全事件均值 → 假阳性损失自动内含；
- \(\delta_{\text{adverse}}\) 由可买子集实测（§3 规则 3）；
- **alpha 从来不是"信号的 alpha"，而是"信号 × 退出规则 × 执行假设"三元组的 alpha**——报告必须写全三元组（V11 双成交假设夹逼精神在退出维度的延伸）。

### 4.6 对称性收尾

进场确认器与退出检测器很可能是**同一个变量的两个区间**：份额分位 <0.50 是"启动值得响应"的前提，>0.90 是"高潮该走了"的警报。若 v2 验证下来 S3（拥挤警报）继续成立而 C4（广度）继续无贡献，整个策略将坍缩为一个极简形态：**在拥挤度低区间等待点火、在高区间离场，中段就是拥挤度从低分位爬向高分位的那段路程**。这将意味着最初的 SMA 份额变量自始至终是系统主角——进场与退出都是它，V11 的错误只是把它的高区间当成了买入键。

## 5. 与 SL-4D 验证设计的映射（概念 → 装置）

| 本文概念 | SPEC 中的装置 |
|---|---|
| 拐点不可预测 → 只做确认 | 信号定义全部为状态确认条件（C1-C5），无预测性声明 |
| 确认的 ROC 驻点 | P6/P7/P12/P13 先验冻结 + T7 邻域扫描（只报告不选参） |
| 早 vs 准的价格表 | v2 S-R2 剂量反应面板（Score 0-4） |
| 中段的期限结构（报价单） | T1 四期限（5/10/20/60）事件研究 |
| 全事件会计 | 事件定义 + 20 日去重，无成功条件筛选 |
| 空退出基线 | Level-2 P1（固定 20 日持有） |
| 对手信号退出 | Level-2 P1b（ALARM 提前退出变体）+ T3/S3 |
| 逆向选择实测 | Level-2.5 可买子集测试（待 S1 通过后启用） |
| 盈亏平衡摩擦点 x* | 建议纳入 Level-2 必报指标（v2 报告要求的自然延伸） |
| 中段原材料的时变 | 分年度报告义务 + 行情段长分布诊断 |
| 启动定位审计（入场位置分位/捕获率/精确率） | 建议作为 v2 报告诊断附件（事后行情段仅作标尺，禁入规则） |

## §0 体系总模型：一场发生在生态里的、数据对抗的接力赛

成熟题材玩法的完整模型由三个嵌套层构成，缺任何一层都会出事故：

1. **内核：接力赛**（Kimi 3 模型，采纳）——题材的生命周期是定价权在三类角色间的接力：点火/空间股（快钱）→ 扩散层（群众资金）→ 容量核心（大资金）。三时钟是三个交接区的传感器，你交易的是交接，不是奔跑。
2. **中层：对抗性数据**（认知篇批判二，Kimi 3 缺失）——行为数据的作者知道你在读它，可信度 = 作者利益与你的对齐度，对齐度随相位翻转。招募期的行为是真诚广告，派发期的行为是对抗性掩护。一切读数须按伪造成本折价。
3. **外层：注意力生态**（Kimi 3 完全缺失）——A 股题材间的注意力与打板资金近似零和。退潮的成因有二：内生枯竭（边际买家买完了）与**外生虹吸（新题材抢走了边际买家）**。因此 SFW-1 的诞生检测器同时是在位题材的退出输入——每个题材的死亡都部分由别的题材的诞生引起。生命周期上下两卷在生态层闭合成环。

## §1 角色系统：连续竞标制

### 1.1 基本法：角色 = 职位，股票 = 在职者

角色不是在题材出生时任命的（Kimi 3 对原论述的纠正，采纳并强化）：先涨停的只是**点火股**——龙头的第一候选人，不是龙头本人。龙头由连续竞标产生：真龙头是在第一次分歧日活下来的那个（断板能回封、核按钮杀不死、全市场复盘拿它当题材温度计），且随时可被卡位换王（质地更纯、盘口更强的候选者高度反超时，市场两三天内完成加冕）。**职位不变（永远需要空间锚、容量载体、溢出接盘），在职者天天可换；行为数据追踪的不是股票，是在职者的更替。**

### 1.2 角色是两条轴，不是一条链

Kimi 3 把角色排成单一接力链，实际是两条独立轴的组合：**资金类型轴**（快钱/慢钱）×**功能轴**（定价锚/容量载体/溢出容器）。区分的意义：大题材里中军可以从早期就与龙头并行上涨（既是容量载体又分担定价锚），不必等交接；补涨股是纯溢出容器——它上涨的唯一原因是龙头买不到了，因此**最后涨、最先死、永远不是买入对象**；补涨潮是高潮信号、退潮先行指标（需求在刮锅底）。

### 1.3 时序分型（对 Kimi 3 接力模型的关键修正）

接力赛的"游资先手"顺序只是默认型。至少三型，时钟读数字典各不同：

| 时序型 | 特征 | 时钟点火顺序 | 误读风险 |
|---|---|---|---|
| 游资先手型（默认） | 点火股连板 → 群众扩散 → 大资金接管 | Fast → Diffusion → Capacity | Kimi 3 表格适用 |
| 机构先手型（政策大题材常见） | 大权重/中字头先动，游资后补空间股 | Capacity → Fast → Diffusion | 按默认表会把机构行情中段误标为"交接进行时" |
| 混合并行型（产业趋势题材） | 中军与龙头同起，浪浪叠加 | 多钟同亮 | "黄金入场窗"判据失去分辨率 |

时序分型应在题材确认后 3–5 日内判定并冻结为该 Episode 的读数字典（占位规则，待校准）。

## §2 定价权迁移：五组脚印的对抗性重排

定价权 = 谁的边际买卖在决定价格；迁移 = 从快钱（买强）向大资金（买弱）移交。Kimi 3 五组脚印保留，但按**伪造成本**重排，并给每组配上对抗性读法（"谁受益于我相信它"）：

| 排序 | 脚印 | 伪造成本 | 对抗性读法（反护盘鉴别） |
|---|---|---|---|
| 1 | 成交额份额迁移（LT = ΔCapacityShare − ΔLeaderShare） | 极高（全组资金流的重心，做不出来） | 须配广度：迁移+广度稳定=交接；迁移+广度收缩=退潮中的相对抗跌 |
| 2 | 相对强度加速（容量组等权 − 题材指数，转正且加速） | 高 | 须持续数周；单周脉冲不算 |
| 3 | 下跌日承接（下跌日容量组 − 龙头组收益差持续为正） | **中——护盘可仿**：派发期托中军维持出货流动性产生同一脚印 | 三重鉴别：时间结构（建仓是数周级安静吸收，护盘是爆发式）；对称性（建仓=下跌日吸收+上涨日缺席；护盘=托底与龙头端派发签名同日共现）；共现检验（同日龙头是否放量滞涨/高位大换手） |
| 4 | 龙虎榜席位结构 | 中低（机构专用席位被量化马甲污染是公开事实） | 只作交叉校准，永不单独定案 |
| 5 | 剩余弹药（拥挤度极值 + 融资增速放缓 + 价格滞涨） | 不可伪造但属状态量非迁移量 | 见 §3 高潮判据 |

**Kimi 3 原文"下跌日的抗跌结构只能是有计划的建仓资金留下的"判定为错误**——删去"只能"，替换为上表第 3 行的三重鉴别。铁律：任何单一脚印不定案，≥2 组高伪造成本脚印同向才确认迁移（跨源校准，§6 第四层）。

## §3 状态系统：四相位 + 三条死亡路径 + 生态输入

### 3.1 四相位行为签名（采纳并修正）

| 相位 | 行为签名 | 操作 |
|---|---|---|
| 启动 | 低基态突跳 + 首板潮同步 + 最高板≥2；梯队单薄但日扩 | 入场区（SFW/SFL 触发管辖） |
| 扩散 | 新增首板不断、晋级率健康、广度扩张、炸板率低、分歧日快速修复（断板次日反包） | 主持仓区；健康分歧（放量充分换手后回封）是加仓点 |
| 高潮 | 拥挤度极值（成交份额自身历史高分位）+ 补涨泛滥（最蹭的票批量涨停）+ 龙头缩量加速（一字连板：无换手缓冲，看似最强实则最脆）+ 媒体研报密集唱多 | 只出不进 |
| 退潮 | 死亡路径逐层兑现（见 3.2）；反抽鉴别：无量、无梯队重建、无新增首板 = 存量自救 | 分级退出；反抽不做（机会成本入账，二波移交 SFL 再激活管辖） |

关键认识（采纳）：**主升与退潮讲同一个故事**——叙事一字未改，改的是梯队高度、广度宽度、炸板率斜率。相位是纯行为构造，故"故事好不好"的判断在成熟段无效；**高潮不是被唱空的，是被买空的**（拥挤度测的不是热度，是剩余弹药：最后一个观望者上车时，边际买家归零，持仓者唯一的动作空间是卖）。

### 3.2 三条死亡路径（对 Kimi 3 解剖顺序的关键修正）

**路径 A：内生退潮（默认型）**——边际需求从边缘向核心枯竭，死亡有解剖顺序：

```
炸板率上升（边缘密封失败）→ 晋级率崩塌 → 新增首板枯竭
→ 最高板断板 → 补涨 A 杀 → 中军补跌
```

顺序的成因：边际买家永远先从边缘退场；最蹭的票封不住板 = 需求枯竭的第一声咳嗽，此时核心还在涨、多数人还在喊强。**先行指标金字塔**（全部领先天数为未校准占位）：炸板率（T+0 盘中）＞晋级率（T+1）＞断板（T+2）＞广度崩塌（T+3~5）＞中军补跌（T+5+）——越靠上越早但噪声越大，越靠下越确定但越贵。

**路径 B：外生截断（监管型）**——特停/核查直接打击龙头：**旗手先死、边缘后死，顺序倒置**。
**路径 C：系统性挤兑（流动性型）**——去杠杆踩踏，全层级同日死亡，无顺序。

**元规则（本体系对 Kimi 3 的最重要增补之一）：死亡顺序本身是诊断量。按序死亡（A 型）→ 按金字塔分级退出；乱序死亡（核心先于边缘）→ 外生冲击，跳过一切"公投等待"，立即清仓。** 剧本有效性的判别器比剧本本身更重要。

### 3.3 生态输入：跨题材虹吸（Kimi 3 缺失的一整只眼睛）

题材间注意力与打板资金近似零和。在位题材的退出监测必须包含生态变量：**新强题材的诞生**（SFW-1 诞生检测器的输出）登记为在位题材的外生退出压力信号——新题材点火日起，在位题材的边际买家池开始被虹吸，其内生指标（炸板率、晋级率）的恶化常随后 1–3 日兑现。系统闭环：**SFW 的进场雷达 = SFL/本 playbook 的退场雷达**。

### 3.4 反抽与二波的诚实处理

"不做反抽"的代价 = 放弃全部二波入场权，此机会成本必须入账而非默然承受。制度性衔接：退潮完成后题材进入蛰伏，其后的再激活（二波）属 SFL 管辖（成熟本体再激活法庭）——本 playbook 的"不做反抽"仅指退潮进行中的存量自救反弹，不覆盖蛰伏后的再激活。鉴别边界（占位）：反抽 = 退潮开始后 10 日内、无量、无梯队重建；再激活 = 蛰伏期（低基态）重建后的新一轮低位跳变。

## §4 时钟系统：交接棒传感器与断板公投

三时钟 = 接力赛三个交接区的传感器（FastClock：连板梯队存在性与高度；Diffusion：非龙头新参与者增量与广度；CapacityClock：大资金接管度，§2 脚印）。基础读数表（**仅适用于游资先手型，其他时序型按 §1.3 换字典**）：

| 时钟组合 | 相位含义 | 策略含义 |
|---|---|---|
| 仅 Fast | 游资独角戏 | 一波流候选，不可重仓 |
| Fast + Diffusion | 群众到场，大资金未动 | 情绪市，仓位受限 |
| Fast + Diffusion + Capacity 刚加速 | 交接进行时 | 入场窗（且容量核心尚有相位空间） |
| Capacity 确认 + Fast 死 | 交接完成或题材换命 | 看三判型：健康交接持有 / 崩溃清仓 / 未分类减档 |

**断板公投**（采纳并补足成本）：龙头断板不是信号，是向全体持仓者提问——这个题材是"龙头教"（龙头死则教亡）还是真协调（换王不亡国）？答案在随后 1–3 日的行为里：容量组断板日有无承接（过 §2 三重鉴别）、外围广度收缩还是稳定。**但听答案的 1–3 日你满仓穿越公投，带着 T+1 与跳空风险——等待有期权费。分级响应正是这笔期权费的支付方式：断板日先减一档，不是因为看清了，恰恰是因为没看清；减档是为"继续听答案"付的保费。** 若 §3.2 判定为乱序死亡（B/C 型），公投程序取消，直接清仓。

## §5 决策系统：相位匹配 + 分级响应

- **进场**：启动确认→扩散段（第二棒起速时）；时序分型判定前半仓封顶；
- **加仓**：仅在扩散段健康分歧（放量充分换手回封）；
- **减仓**：高潮签名（拥挤极值/补涨泛滥/龙头一字化）任two同现 → 减半；
- **退出**：信号层级 ↔ 动作幅度映射——炸板率/断板（快而噪）→ 减档；高潮拥挤（结构信号）→ 减半；广度回撤+相对强度转负（慢而确定）→ 清仓；乱序死亡/跨题材虹吸+内生恶化共现 → 立即清仓；
- **自体容量约束**（Kimi 3 缺失）：自身委托占题材成员日成交额的比例设上限——你的单子也是别人读的行为数据，规模到了阈值，你就从读者变成了被读者；
- **总纪律**：永远在旗手倒下之前离场，因为你读的是外围的死亡，不是核心的死亡；你交易的是交接，不是奔跑。

## §6 工程护城河：四层结构与衰减

采纳 Kimi 3 四层并补充：

1. **结构化降维**：把 5000 票×行情×席位×公告的噪声海压缩为"题材×角色组×时钟状态×相位"低维状态空间——决策质量取决于状态空间的信噪比，不取决于数据量。同一张梯队表，散户读出"今天几个板"，架构读出"新兵入伍速率 − 边缘死亡速率"；
2. **版本化与 PIT 纪律**：as-of 记录、冻结分母、叙事卡——直接回报不是回测更准，是**更快的证伪**；在自适应市场里，埋葬坏策略的速度比优化好策略的能力更值钱；
3. **状态机×分级响应**：对手盘跑二元启发式（买/卖/拿着），你跑"信号层级→动作幅度"映射——不是预测优势，是决策结构优势；
4. **跨源校准**：单源皆噪声（席位可以是马甲、承接可以是护盘、放量可以是对倒）；≥2 组高伪造成本证据同向才定案——交叉校准产生任何单源都没有的信息。

**衰减与河床**：护城河按可抄性分层衰减——数据（已免费）→ 结构化（正在被 vendor 复盘工具商品化）→ 状态机（正在被模仿）→ 纪律（预注册 Kill、自由度记账、按计划杀死自己的策略）。纪律难抄不是技术原因，是心理原因。**护城河层级与信号层级存在同一个对称律：市场里，信号可信因为发出它昂贵（封板）；系统里，防御可靠因为执行它昂贵（自我证伪）。贵，是两边共同的认证机制。**

## §9 深刻洞见（收束）

**洞见一：题材死于别的题材的诞生。** 内生枯竭只是死因之一；注意力零和生态里，边际买家是守恒量，每次新谢林点的点燃都在抽干旧谢林点。由此系统闭环：诞生检测器（SFW）与退出监测器（本体系）是同一台仪器的两个读数方向——**看见下一个题材出生的能力，就是从这一个题材活着出来的能力。** 生命周期上下两卷不是两个策略，是一个生态的两只眼睛。

**洞见二：剧本的价值不在剧本，在剧本失效的判别器。** 解剖顺序、金字塔、公投——全部是默认路径的剧本；真正保命的是元规则"顺序错乱 = 外生冲击 = 换剧本"。任何行为剧本都会遇到不按剧本演的日子，体系的等级差不在谁的剧本更细，在谁能最快识别"今天不是剧本内的戏"。

**洞见三：等待有期权费，分级响应是它的支付方式。** 断板后听公投答案的 1–3 天、承接鉴别所需的数周——一切"看清楚"都要用敞口时间购买。二元决策者要么拒付（错过）要么全付（满仓穿越不确定）；分级响应把期权费拆成分期付款：减档不是判断，是**为继续观察支付的、经过定价的保费**。这是决策结构优势的本质：同一信息流，更好的赔率结构。

**洞见四：贵是唯一的认证机制，市场与系统两侧同构。** 市场侧：信号可信因为发出它昂贵（封板吃掉全部卖单）；数据侧：读数可信按伪造成本排序（份额迁移＞承接＞席位）；系统侧：护城河可靠因为执行它昂贵（自我证伪的心理成本）。整个体系其实只有一条公理：**在博弈环境里，凡是便宜的都不可信——包括你自己便宜的自信。**

**洞见五：体系的真正输出不是预测，是被夺回的决策日历。** 这套体系没有一处宣称知道明天涨跌；它做的是把"何时必须做决定"从情绪手里夺回来——断板日+1 是公投读数日、拥挤极值日是减半日、乱序死亡日是清仓日、新题材诞生日是复核日。成熟段多数人的亏损不是判断错误，是**决策时点被行情牵着走**；把决策点钉死在行为地标上，纪律才从美德变成程序。

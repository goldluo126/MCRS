## 1. 闸门修正案（G-DQ3 → G-DQ3a/3b/3c）

**修正理由（先说清为什么这不是"改闸门让它通过"）**：SPEC v2 R1 在本次失败**之前**已登记"板块价格与成交额主口径切换为官方 sw_daily，成分聚合仅作交叉验证"。因此 C1/C2/C3 不再依赖聚合，旧 G-DQ3 检验的问题（聚合能否复刻官方指数）已无承重对象；聚合的唯一承重用途是 C4 广度与 C5 涨停（必须逐股计算的量）。新闸门检验真实风险（成分表用于广度/涨停是否足够准），且整体**更严**：新增了旧闸门没有的定量护栏 3c，3a 结果全量保留不隐藏。

### G-DQ3a（降为诊断项，无通过线）
- 聚合 vs 官方的 amount 与 return 相关性，输出**逐板块 × 逐年全矩阵**（31×13 两张表）进 DATA_AUDIT_v2；
- 对齐规则：逐指数按其官方序列实际起点做 inner-join；任何 NaN 填充参与相关性计算均为 bug；
- 此矩阵同时是 RC-1/2/3/4 的定位地图：低相关格子集中在 11 个短序列板块的早年 → RC-2；集中在小板块全时段 → RC-1；amount 高但 return 低 → RC-3；集中在 2021 新设板块的 2021 前 → RC-4。

### G-DQ3b（新硬闸门，失败仍写 GATE_FAILED.flag）
1. **覆盖率**：每交易日，有行情股票中拥有 PIT 板块映射的比例 ≥ 97%（全市场口径，逐日序列进审计）；
2. **加权对齐相关性**：用**自由流通市值加权**（`daily_basic.free_share × close`，D-1 时点，对齐 V11 §3.1 口径）的聚合收益 vs 官方指数收益，2021-08-01 之后区间逐板块 corr > 0.97。加权口径对齐官方后，残余差异只剩成分错误——这是把 RC-3 从 RC-1 中剥离的手术刀；
3. **抽样核对**：每板块随机抽 5 只官方当前成分股，与重建后的 membership 表比对，不一致数 = 0。

### G-DQ3c（新硬闸门，广度稳健性护栏）
- 对重建后的成分表注入随机扰动（每板块随机增/删 10% 成员）× 200 次；
- 每次扰动下重算 Breadth 与 C4 触发集合；
- 通过线：C4 触发的 (板块, 日) 集合与未扰动基准的 Jaccard 相似度中位数 ≥ 0.8；
- 语义：给"成分表足够好"一个可证伪的定量定义——若广度信号对 10% 成分误差都不鲁棒，则无论成分表多准都不该信任 C4。

### RC-4 的分段验收
- 2021-08 之后：G-DQ3b 三项必须全部达标；
- 2021 之前：3b-2 达不到 0.97 的板块逐一列表、量化偏差（corr 值 + 偏差集中年份）、写入 Limitations；
- **新增稳健性检验（登记入主流程）**：DEV 主判据（S-R1/S-R2）完成后，追加"剔除回填受损板块子集"重跑，结论方向必须不变，否则主结论标 FRAGILE。

## 3. 边界与停止条件

- **允许动的**：成分表构建、对齐逻辑、单位换算、闸门实现——一切装置层；
- **禁止动的**：C1-C5 定义、P1-P18、事件定义、去重规则。判别法不变：改动若会改变"哪些 (板块, 日) 触发信号"（数据修复导致的除外），即属信号层，禁止；
- **停止条件**：Step 2 重建后 G-DQ3b-2 在 2021-08 后区间仍有 > 3 个板块 < 0.97 → 停止上报（说明成分重建存在未定位的系统性问题，不许试第四种修法）；G-DQ3c Jaccard < 0.8 → 停止上报（广度信号对成分误差不鲁棒是设计级问题，轮不到你修）；
- 每个修复决定（改了什么、为什么、影响哪些数字）记入 REPORT_v2.md Decisions 节。

## 3. 协调跃迁过滤器

### 3.1 LUShock v4：异质倾向 + 精确 Poisson-binomial（替代板块同质 Z）

```
个股涨停倾向（PIT，逐日）:
  p_i,D = 股票 i 过去 250 日涨停频率，在 {交易板块 × 市值三分位 × 股性三分位} 层内
          向层均值收缩（shrinkage λ=0.5），下限 0.001、上限 0.30
          # 股性 = 过去 250 日涨停次数分位；三变量层承载市值/波动/动量的主要异质性

题材涨停富集（对 EpisodeBaseSet 或 Members_{D−1}）:
  P_tail(c,D) = P( X ≥ LU_{c,D} ),  X ~ PoissonBinomial({p_i,D})   # 动态规划精确计算，n≤100
  LUShock(c,D) = −log10( P_tail )
点火条件: LUShock ≥ 3  ∧  LU_{c,D} ≥ 2（绝对地板，防微期望伪异常）
```
- **多重性纪律**：每日对全部休眠题材扫描属多重检验。处置：① 精确尾概率+绝对地板+簇去重已压低假点火；② MUST 报告"零模型下预期每日假点火数"与实际点火数对比（诊断义务）；③ 不采用逐日 BH（触发将依赖他题材数据，损害可复现性——设计留痕）；
- **稳健性口径（登记）**：分层条件置换（层内打乱涨停标签 1000 次的经验尾概率）作 LUShock 的平行计算，仅报告。
- BombRate（触板 ≥3 时定义，≤0.5）、MaxBoard（保留原始值）沿 v3。

### 3.2 Episode 状态机（沿 v3 §3.2，成员集口径按 §2.5 修订）

## 11. 判定标准：三分法 + MES（v4 核心修订）

**冻结 MES**：事件级 10 日成本后超额 50bp ∧ Cohen's d 0.2（两者同时作为经济意义下限）。

| 判决 | 条件 |
|---|---|
| PASS | 置换检验显著（单侧 95 分位外）∧ CI 下界 > 0 ∧ 点估计 ≥ MES |
| FAIL | CI 上界 < MES（有证据表明效应低于经济意义下限） |
| INCONCLUSIVE | 其余（CI 跨越 MES）——判词写"未证实/功效不足"，MUST NOT 写"已证伪" |

判决层级：第一法庭 H-Z2 于影子数据 **FAIL** → 过滤器家族死亡（科学结论）；INCONCLUSIVE → 家族未证实，项目照常按 §0 关线（管理决定，判词分开写）。第二/三法庭失败不上溯。E1/E2/E3 与 NetConfirmationValue 必报（相位命题与确认净价值的直接证据）。

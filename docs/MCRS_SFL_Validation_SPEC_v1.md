## 1. 经济先验登记（动机，非证据）

**操纵不对称 → 信号可信度不对称 → 架构角色分配**：游资可操纵个股走势，但有持续性的主题叙事需要主力资金集团化共识（谢林点）。集体买入某主题筹码 → 板块量价状态变化难以伪造（造假成本 = 拉动全板块成交额）；主力体量大、进出慢 → 板块趋势有持续性。推论：板块状态是"真故事发生中"的可信指示器（过滤器），alpha 载体是主题内的信息领先个股。

**可测蕴含（H-F5 诊断）**：板块突破的续航率应高于个股突破的续航率。注：该现象亦可由"平均消灭特异波动"机械解释，本实验只测现象、不辨成因——架构只需现象成立。

## 3. 四臂因子设计（归因的生死线）

| 臂 | 板块过滤 | 选股 | 回答什么 |
|---|---|---|---|
| **T**（处理） | 启动态板块 | LNC 前三 | 端到端主判据（H-F1） |
| **A**（过滤对照） | **随机板块**（同日、同数量） | LNC 前三 | 过滤器效应（H-F2）= T − A |
| **B**（选股对照） | 启动态板块 | **同板块随机三只**（可交易成分中抽取，200 次重复取分布） | LNC 效应（H-F3）= T − B |
| **N**（朴素对照） | 启动态板块 | 板块内 20 日 RS 前三 | LNC vs 廉价替代（H-F4）= T − N |

四臂同一事件日历、同一入场/退出/成本规则。加法分解：端到端 alpha ≈ 过滤器效应 + 选股器效应 + 交互 + 退出效应（EXIT-3C vs 空退出的差）。基准：等权 31 板块（主）、沪深300（副）。

## 4. 规则定义

### 4.1 板块过滤器（a1）
- **主定义**：LAUNCH = C1∧C2∧C3∧C4（SL-4D v1 冻结定义原样复用：低拥挤 <0.50、量比 ≥1.3×3 日、价格穿越、广度低位跳变；P1-P18 不变）；C5 涨停结构做记录不做条件；
- **副定义（功效动机）**：Score ≥ 3（四条件满足其三）。选择理由 = 样本量算术（LAUNCH 角点 46 事件 × 3 股不足以支撑个股级推断），**非 DEV 表现——诚实标注：设计方已看过 DEV 剂量反应，此选择有污染嫌疑，故 OOS 为唯一法庭**；
- 事件去重 20 交易日（P16）；触发日 = D；候选板块集 S1(D)；
- **融资余额**：本轮仅作诊断伴随变量记录（披露 T+1 滞后、新机器引入会搅浑归因），不进过滤条件。

### 4.2 LNC 龙头计分（a2；V11 §3.3 精简实现）
对 s ∈ S1(D) 的可交易成分（PIT，剔除停牌/上市<120日/退市整理）：
1. 残差化：$\tilde r_{i,t} = r_{i,t} - \hat\beta_{i,m} r_{m,t} - \hat\beta_{i,s} r_{s,t}$，β 用 D-120:D-1 估计，$r_m$=沪深300，$r_s$=板块等权；
2. 滞后相关 $\rho_{ij}(\tau)$，τ∈{1,2,3}，窗口 120 日，全 τ×双向联合 BH-FDR ≤ 0.05；
3. 建边条件（V11 §3.3 四条）：FDR 通过、方向差 ≥0.05、≥2 个 τ 方向稳定、配对覆盖率 ≥0.8；
4. 出强度中心度 $Cent_i = \sum_j W_{ij}$，$W_{ij}=Stability_{ij}\cdot\max(0,\rho^+_{ij}-\rho^+_{ji})$；
5. 取中心度前 3 名为买入标的 **L1/L2/L3**（改名避免与条件 C1-C5 撞名）；
6. **稀疏回退**：建边后合格节点 <3 → 取实际数量（≥1）；=0 → 该事件跳过并记 `lnc_sparse_skip`（诊断 FDR 稀疏率）。

### 4.3 入场与可成交（a3）
- D+1 **开盘价**（open_raw）买入；副口径 D+1 VWAP 并报（V11 双成交假设纪律）；
- 开盘涨停（open_raw ≥ limit_up）或停牌 → 剔除，顺位替补至中心度第 5 名；仍不足则少买；记 `dropped_leader`（逆向选择的直接测量）；
- 2019 年前 stk_limit 覆盖缺失时用规则回退（pct_chg ≥ +9.8% ∧ close==high 判涨停），标 `limit_approx=true`；
- 等权分配：每事件 3 只各 1/3 事件资金；组合层并发上限 4 个事件（12 只持仓），超出按 ΔBreadth 排序截断；空余资金持现金记 0。

### 4.4 持仓状态机（a4，最小实现）
逐日（≤D 数据，D+1 执行）评估每只持仓：所属板块的 Breadth_s / CrowdPctl_s / RS20_s + 个股停牌/退市状态。无风控阶梯（研究阶段，仓位恒定），无加仓。

### 4.5 退出（a5）
- **主方案 EXIT-3C**（用户定义原样登记）：
  - Leg A 失败确认（进场后 ≤10 交易日）：Breadth_s < 0.30 → 全部退出；
  - Leg B1 高潮减仓：CrowdPctl_s > 0.90 → 减至半仓（仅一次）；
  - Leg B2 顶部确认：Breadth_s ≤ 进场后峰值 −0.20 ∧ RS20_s < 0 → 余仓退出；
  - Leg C 论点过期：满 60 交易日 → 退出；
  - 优先级 A > B2 > B1 > C；
- **空退出对照**：固定 20 交易日（EXIT-3C 必须净胜它，H-F6）；
- **登记变体 V-STOP**：EXIT-3C + 个股安全腿（个股相对板块 20 日超额 < −15% → 单股退出）——个股特异灾难防护，主方案不含，数据裁决；
- 卖出按 D+1 收盘价；跌停/停牌按 V11 §8A.4 顺延（卖不掉诚实建模，滞留期计入收益）。

### 4.6 成本
买入 12.5bp（佣金 2.5 + 冲击/滑点 10）；卖出 17.5bp（佣金 2.5 + 印花税 5 + 冲击/滑点 10）；印花税 PIT（2023-08-28 前 10bp）。毛/净并报；报告盈亏平衡摩擦点 x*。

## 5. 归因会计（a6）
必报分解表：T 臂净超额 = 过滤器效应（T−A）+ 选股效应（T−B）+ 基线（A∩B 隐含）+ 退出效应（EXIT-3C − 空退出）− 成本 − 逆向选择（dropped_leader 影响：含被剔除龙头的影子组合对比）。另报：H-F5 续航率对比表、LNC 稀疏率、分年度、牛熊分层、x*。

## 6. 统计与功效（算术前置）
- 主推断：日历时间法（T 臂日净超额 vs 等权基准，NW-t lag=10 + Block Bootstrap 5/10000），有效持仓日 ≥500 才可判定；
- 事件级：20 日净超额 Block Bootstrap CI + Cohen's d；
- 功效预算：个股 20 日超额 σ≈15%，检出 d=0.2 需 ~200 个股级事件；LAUNCH 角点预计 ~130（46×3 减 dropped），不足 → 主读数以日历时间法为准，角点事件级降为描述性；Score≥3 臂预计事件充足；
- 安慰剂闸门 G-PLACEBO-S（解锁真实结果的前置）：① 时移 +20 日全管道，|d|<0.1；② 同日同板块随机选股零分布（= B 臂机器复用）居中无漂移。

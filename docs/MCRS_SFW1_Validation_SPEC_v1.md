## §0 研究对象与哲学基础

### 0.1 检测语义的根本转换：诞生检测，不是相变检测

v13 检测**成熟本体的再激活**：单元（vendor 概念）长期存在，观测其 DORMANT→IGNITION 状态跃迁。SFW-1 检测**题材的诞生**：单元在事件发生时才成为可观测对象，不存在休眠历史。（分析文档批判二）

两者是不同的统计问题：

| | v13（相变） | SFW-1（诞生） |
|---|---|---|
| 单元 | 先在（vendor 概念，as-of） | 事件时构造（语义种子 / 联动簇） |
| 零假设 | 该单元本期跃迁概率 = 条件基率 | 本期出现"前所未见成员集"的概率 = 条件基率 |
| 新颖度维度 | 无（单元身份连续） | 核心（相对历史簇库与概念库的成员集新颖度） |
| 错误预算 | 年度假点火数 | 年度假诞生数（§7） |

### 0.2 alpha 来源与其时效性声明

SFW-1 的候选 alpha = **认知延迟差**：`f(全市场确认延迟 − 本系统确认延迟)`，即语义+行为管道与 vendor 编辑管道之间的 3–10 天。按构造这是**衰减性 alpha**（NLP 题材雷达普及将系统性收窄延迟差）。因此（分析文档洞见三）：

- 所有判词**必须带时效戳**：结论形如"截至评估期 T，效应存在/不存在"，禁止无时限宣称；
- OC 漂移监测（§8.4）新增强制维度：**延迟差衰减**（vendor 概念创设日相对本系统事件日的滞后分布的滚动趋势）；
- 证据保质期条款：任一法庭 PASS 后，若延迟差中位数相对判决期收窄 ≥50%，判决自动降级为 `STALE`，重新进入监测。

### 0.3 三层盲区量化义务（立项前置）

第一浪的"最肥"须打三层折扣：单元层（vendor 滞后——本 SPEC 主修）、数据粒度层（日频接不住 D0–D2 执行）、执行层（一字板买不进）。（分析文档洞见四、批判四）

**强制预注册测量**：每个事件按三口径同时记账——

1. `R_paper`：法定分母全成员，E0+2 收盘 MTM（含不可买成员）；
2. `R_buyable`：剔除入场时刻涨停锁死/停牌/ST 成员后的 MTM（可买子集，入场价按 E+1 规则）；
3. `R_executed`：可买子集按 VWAP+滑点、参与率上限（[继承] v13 §8A 执行模型）的成交口径。

`R_paper − R_buyable` = 执行层盲区；`R_buyable − R_executed` = 摩擦；三口径差异本身是一级研究产出。**若 DEV 期 `R_buyable` 系统性 ≤ 0，则"第一浪在日频合同下可交易"被证伪，程序按 §12 终局条款处置——不允许以纸面口径续命。**

### 0.4 假设族（预注册）

- **H-W0（可执行存在性，承重假设）**：第一浪事件（§6 定义）的 `R_buyable`（E0+2 → E0+12，法定分母口径）> 0，且 > 同日特征匹配随机篮子（§8.1 对照）；
- **H-W1（科学信息）**：第一浪事件携带前向信息：事件组相对匹配对照的超额收益在族校准下显著；
- **H-W2（端到端可执行）**：`R_executed` 口径、计入全摩擦与假资本日后，策略净值优于对照策略；
- **H-W-U0×U2（来源分解）**：文本先导（U0-born）与行为先导（U2-born）事件分层报告，禁止合并宣称（两臂循环性风险不同，见 §5.6）；
- **H-W-decay（衰减监测，只监测不检验）**：延迟差与效应量的滚动趋势。

FWER 控制：H-W0/W1/W2 进入 Bretz 图初始权重 (0.5, 0.3, 0.2)，图规则与 α-spending [继承] v13 §9；分层与监测假设为描述性，不占 α。

## §3 U0 语义种子集

### 3.1 种子集构造

一个 U0 单元 = `(theme_key, 版本化成员表, 来源记分账本)`。`theme_key` = 规范化叙事关键词（新词监测触发：关键词在 T1 权威文本中首次出现，或 T2/T3 中 20 日滚动提及频次相对 120 日基线富集 ≥ 5 倍且绝对提及 ≥ 8 家不同公司）。

### 3.2 来源记分（Provenance Scoring，冻结规则）

每个候选成员按证据硬度记分，**只用文本证据，不用价格行为**（反循环规则一，§5.6）：

| 证据类型 | 分值 |
|---|---|
| 公告/年报载明相关收入占比 ≥5%、在手订单、产能数字 | +3（硬） |
| 政策文件/权威名单点名该公司 | +3（硬） |
| 董秘确认有相关业务但无量化数字 | +2 |
| 董秘"关注/研究该领域"、无业务实体 | +1（软） |
| 澄清公告 / 互动易否认 / 监管问询提示蹭热点 | −∞（当日剔除，负证据通道） |

**核心层准入线：score ≥ 3 且无负证据。** 外围层：1 ≤ score < 3。记分规则冻结于本表；实施 Agent 须将文本→分值的判定写成确定性规则（关键词+正则+数字抽取），禁止运行期人工裁量；无法自动判定的条目落入外围层并挂 `manual_review` 旗（旗子只影响诊断，不影响分母）。

### 3.3 版本治理

U0 成员表每日收盘后版本化（`u0_{theme}_{date}.json`，append-only），每次增删记 `(member, action, evidence_ref, rule_id)`。可审计性即 PIT 卫生。

### 3.4 U0 点火检测（种子集共激活富集）

对版本 as-of D−1 的 U0 核心层 S（|S| ≥ 5）：

- 激活定义 [继承 v13 强激活口径]：涨停收盘 或 盘中触板 或 当日涨幅 ≥ 主板 7% / 创业板科创板 14%；
- 检验统计量：S 中 D 日激活数 k；
- 零模型 [继承] v13 分层条件置换（板×市值×波动×动量×股性分层，保持当日各层激活总数，重排标签），LUShock 逐集合版本：`p_D = P_null(K ≥ k)`；
- **U0-IGNITION**：`p_D ≤ α_ignite` 且 `k ≥ 2` 且行业条件富集存活（[继承] v13 行业条件零模型——排除"整个行业普涨"解释）。

`α_ignite` 不拍脑袋：由 §7 假诞生预算经路径级零模型反解校准。

## §4 U2 涨停共激活簇（LAC）

这是最重要的新机器。设计原则：**共现本身不是信号，超出条件预期的共现富集才是**（分析文档批判一）。

### 4.1 边定义：条件富集，不是原始共现

滚动窗口 W = 10 个交易日。对窗口内至少各有 1 个激活日的股票对 (i, j)：

1. 观测：共激活日数 `c_ij` = 窗口内 i、j 同日激活的天数；
2. 零模型：对窗口内每个交易日，做 [继承] v13 分层条件置换（保持每层当日激活数、重排层内标签），B = 2000 次（种子冻结 `seed = SHA256(date‖"lac")` 截断，[继承] v13 派生规则）——得到 `c_ij` 的置换分布；
3. 边权：`p_ij = (1 + #{置换 c ≥ 观测 c}) / (1 + B)`；
4. **建边条件（全部满足）**：`p_ij ≤ 0.01` 且 `c_ij ≥ 2`（绝对下限，防单日巧合）且 i、j 非同一申万一级行业**或**行业条件置换下仍 `p_ij ≤ 0.01`（行业内对须过更严的行业条件零模型，排除行业 beta 解释）。

计算可行性：每日仅对窗口内激活过的股票配对（典型 200–600 只，≤ 18 万对，其中过 `c_ij ≥ 2` 初筛的通常 <1 万对，逐对置换可行；置换在层内一次性重排、所有对共享同一批置换样本，复杂度 O(B × 日激活数)）。

**高潮日退化防护**：全市场激活数进入自身 750 日 P95 以上的日子，该日在零模型中按当日实际激活总数条件化（自动收紧——激活基率越高，共现的条件预期越高，边越难建立）。这是"天量日全连通"问题的结构性解，不设人工开关。

### 4.2 确定性聚类 [继承算法，换输入]

在当日显著边集上运行 [继承] v13 §2.2 确定性 clique 贪心：边按 `(p_ij 升序, c_ij 降序, 股票代码对字典序)` 全序排列，依次处理；两端均未入簇→建新簇；一端入簇→当且仅当新股与簇内**全部**成员均有显著边时并入；两端在不同簇→当且仅当两簇跨边完备时合并。无随机性、无分辨率参数、双 Agent 必然同哈希——社区发现与宪法的冲突以放弃模块度类算法为代价解决（分析文档批判三）。**簇候选门槛：|簇| ≥ 4。**

### 4.3 簇谱系（身份治理）

"没有成分回填"的对价是"没有稳定身份"，此对价在谱系账本中入账（分析文档批判三）：

- 每日簇与前一日活簇按 Jaccard 匹配：J ≥ 0.5 → 继承谱系 ID（多对多时按 J 降序、谱系 ID 字典序贪心，规则 [继承] v13 谱系条款）；
- 分裂：最大 J 分支继承 ID，其余开新 ID 并记 `parent`；合并：成员多者 ID 存续，记 `absorbed`；
- 谱系连续 5 日无当日簇匹配 → 谱系 `EXPIRED`（可被后日 J ≥ 0.5 复活，记 `revived`）；
- 谱系账本 append-only，冷却、去重、独立事件计数全部以谱系 ID 为键。

### 4.4 U2 诞生检测（新颖度条件）

**U2-BIRTH** 事件：当日出现新谱系 G，满足全部——

1. |G| ≥ 4，簇内边中位 `p_ij ≤ 0.005`（质量线）；
2. **新颖度**：G 的成员集相对（a）过去 750 日全部谱系历史成员集、（b）全部 as-of 存续 vendor 概念成员集、（c）申万一二级行业成员集，最大 Jaccard < 0.3——三库任一命中即非诞生（是再激活/已知结构，移交 SFL 语义，不入 SFW）；
3. 次日存续：G 在 E0+1 仍有匹配簇（J ≥ 0.5）——单日闪簇不算诞生。

诞生日 E0 = 新谱系首现日；确认以 E0+1 存续为准，因此**事件登记时刻 = E0+1 收盘**（无前视）。

## §5 成员集与法定分母（问题 4 的可执行化）

### 5.1 分层成员制

- **核心层** = 状态变量的**法定分母**（EpisodeBaseSet）；
- **外围层** = 仅用于扩散观察、晋级率诊断、负向降级——**任何状态变量的分母永不包含外围层**。

### 5.2 U0-born 事件的法定分母

= 点火日 as-of 的 U0 核心层（纯文本准入，score ≥ 3），**冻结于 E0**。持仓期内：新文本证据可将外围成员晋级——但只改**下一个**事件的分母，本事件分母不动；负证据通道触发的剔除实时生效并记账（剔除是风险控制，不是信号优化）。

### 5.3 U2-born 事件的法定分母与循环性处置

U2 簇成员按行为准入，行为准入 + 行为状态变量 = 部分同义反复（分析文档批判五）。冻结的缓解方案（时滞分离 + 证据更新）：

- 法定分母 = E0 簇成员，冻结；
- **状态变量测量自 E0+2 起**，且确认统计量只使用 E0+2 之后的激活/富集证据——准入窗口（E0−9 … E0+1）的行为证据**不得**再次进入确认检验；
- 扩散诊断使用外围层（与核心有显著边但不在 E0 簇内的股票）的增长，仅作伴随变量；
- **诚实声明**：时滞分离降低但不消灭准入循环性。U2-born 臂在报告中永久携带 `admission_circularity` 旗，与 U0-born 臂分层报告、禁止合并宣称（H-W-U0×U2）。

### 5.4 反循环三规则（机器断言，违反即 GATE_FAILED）

1. 任何信息源不得同时出现在"准入条件"与"该事件的确认统计量"中，除非时滞分离 ≥ 2 个交易日；
2. 状态变量分母只含核心层且冻结于 E0；
3. U0 核心层准入永不使用价格/成交行为（行为只能降级、不能晋级入核心）。

### 5.5 负证据通道

澄清公告 / 互动易否认 / 问询函提示蹭热点 → 该成员当日从核心层剔除（若在持仓中，次日开盘按 [继承] v13 §8A 执行模型退出该成员）。剔除事件全部入账，`vendor 剔除滞后 − 本系统剔除时点` 作为速度差 alpha 的直接测量登记。

### 5.6 晋级率伴随变量

外围→核心晋级速率、U0 文本种子的行为兑现率（种子中 E0–E0+5 实际激活比例），登记为题材健康度伴随变量（叙事自我实现的直接观测），不占 α。

## §6 事件状态机与交易合同

### 6.1 事件时间轴（冻结）

```
E0      诞生/点火日（U0-IGNITION 或 U2-BIRTH 的首日）
E0+1    事件登记（U2 需存续确认；U0 当日即登记）
E0+2    确认地标（landmark）：确认统计量结算 → CONFIRMED / FAILED
E0+3    入场日：开盘后按可买规则建仓（VWAP 口径，[继承] v13 §8A）
E0+12   基准评估终点（10 个交易日持有；退出规则 [继承] v13 EXIT 合同）
```

对比 SFL 的 D0+5 入场，SFW-1 把确认延迟压到 E0+3——这就是"越早越肥，但越假"权衡的冻结点；E0+1 探针臂（更早入场）只作描述性记账，不入检验，不占资金预算。

### 6.2 确认统计量（E0+2 结算）

CONFIRMED 当且仅当（法定分母口径、遵守 §5.4 时滞规则）：

- U0-born：E0+1 与 E0+2 两日中至少一日种子富集 `p ≤ α_confirm`，且累计激活成员 ≥ 3，且 GapLimit 守卫通过（[继承] v13：分母中入场时可买成员占比 ≥ 40%，否则 `UNBUYABLE_SKIP`——照实入账，不作剔除样本处理）；
- U2-born：E0+2 单日（准入窗外）簇成员再富集 `p ≤ α_confirm` 且新增激活（准入窗内未激活的核心成员）≥ 1，且 GapLimit 通过。

FAILED / UNBUYABLE_SKIP 事件全部入账（假诞生预算与假资本日核算的分子）。

### 6.3 冷却与去重

同一谱系 ID / 同一 `theme_key`：事件结束（退出完成或 FAILED）后 20 个交易日冷却；U0 与 U2 事件若成员集 Jaccard ≥ 0.3 且 E0 相差 ≤ 3 日 → 合并为单一事件（U0 为主、记 M1 映射），防止同一题材双重计数。

### 6.4 诞生类型分型（分层报告，不占 α）

- `POLICY`（E0 触发源含 T1）：预期窗口 D1–D3 极快；
- `EVENT`（T4 日历命中 E0±5 日）：存在潜伏盘、"见光死"风险——**分层登记，本期不为其定制打法**；
- `TREND`（纯 U2-born 无文本源）：联动簇机器的主场。

### 6.5 组合与资金合同 [继承]

事件预算制现金流 P&L、部分成交、未分配资金、假资本日（FalseCapitalDays）核算 [继承] v13 §8B。每事件等权买入法定分母中可买成员（无中军筛选——第一浪期中军通常尚未出现；容量地板放宽为成员 ADV ≥ 3000 万元，放宽的代价在 `R_executed` 口径如实体现）。

## §7 错误预算与阈值校准

- **年度假诞生预算**：E[假诞生事件/年] ≤ 6（U0、U2 两臂合计）。校准方法 [继承] v13 路径级零模型机器：在保持个股特征与市场日历、破坏题材对齐的合成年（全路径互换 + 边可行性预计算 + 三阶段最优指派，逐字继承）上运行完整 SFW 检测管道（U0 臂在合成世界中用真实文本×合成价格——文本与价格的对齐被破坏，正是所需的零世界），反解 `(α_ignite, α_confirm)` 使合成年均事件数 ≤ 6。**阈值由预算反解，不由效应大小正推。**
- **零世界诞生率**是 G 门之一（G-W1）：若合成年假诞生数对 `(α_ignite, α_confirm)` 不可控（阈值收紧到 α=0.001 仍 >6），则诞生检测器分辨率不足，程序停在此处，不进法庭。
- 假资本日预算 [继承] v13 数值与核算法。

## §8 法庭

### 8.1 W1 科学法庭（H-W1）

- 估计量：CONFIRMED 事件法定分母的 `R_paper`（E0+2 收盘 → E0+12 收盘，Total Return Ledger MTM）；
- **对照**：同日特征匹配随机篮子——在 E0+2 当日，从全市场（剔除法定分母及其外围层）按分层特征（板、市值、波动、动量、股性五维，[继承] v13 分层定义）抽取与法定分母同规模、层分布一致的随机篮子 200 个（种子冻结），配对差 = 事件篮子收益 − 匹配篮子收益中位数。诞生事件没有"休眠题材风险集"可匹配，特征匹配随机篮子是唯一干净对照（S1c 血统）；
- 检验：[继承] v13 事件时钟组序框架 + Westfall-Young maxT 族校准 + Bretz 图（§0.4 权重）；`n_target` 由 DEV 期事件率与最小关注效应（配对差 ≥ +1.5%，10 日）反解，[继承] v13 反解程序。

### 8.2 W2 可执行法庭（H-W0 / H-W2）

三口径记账（§0.3）为强制输出；H-W0 检验 `R_buyable` 口径配对差；H-W2 检验 `R_executed` 口径端到端净值（全摩擦 + 假资本日）对可比基准（[继承] v13 基准合同）。**诚实声明（冻结入报告模板）**：日频 VWAP 执行模型对 D0–D2 入场是乐观上界的**反面**——第一浪常态是买不到而非买贵，`R_executed` 在此处是不可靠估计；W2 若 PASS 仅证明"日频合同下限仍为正"，若 FAIL 须区分"策略无效"与"日频粒度不足"（后者触发 [继承] v13 L1 数据晋级出口，作为后续程序立项条件，不改变本程序判决）。

### 8.3 安慰剂族（G-W 门）

1. **时间安慰剂**：真实事件日 ±20–60 日随机伪 E0（同谱系/种子集），效应应消失；
2. **标签安慰剂**：同日等规模随机"伪种子集"跑完整确认管道，CONFIRMED 率应 ≈ 零世界基率；
3. **零世界诞生率**（§7 G-W1）；
4. 双 Agent 独立复算同哈希验收 [继承] v13 全套协议。

### 8.4 OC 漂移监测（含衰减维度）

[继承] v13 OC 框架，新增强制维度：**延迟差衰减**——每季度测量 `vendor 概念创设日 − 本系统事件 E0` 的滞后分布（对期内可映射 M2 的事件），滚动趋势入 OC 面板；中位滞后收窄 ≥50%（相对 DEV 期基线）触发 §0.2 判决降级条款。

## §9 分期与判决

[继承] v13 分期骨架（DEV / OOS-A / OOS-B 锁箱、alpha-spending、判决树），仅改动：

- DEV 起点受文本普查（G-T）约束：文本可回溯段才可入 DEV；不可回溯的源走前瞻收集（Run-in 逻辑 [继承]）；
- U2 臂无文本依赖，可全 DEV 段回测；U0 臂按 G-T 结果确定可用段——**两臂样本期不同属正常，报告须明示各臂样本期**；
- 判决带时效戳（§0.2）。

## §10 与 SFL 的接口

**共享（同一实例，不复制）**：快照库、Total Return Ledger、分层条件置换机、路径级零模型生成器、执行模型 §8A、资金合同 §8B、双 Agent 协议、G-DQ 门。
**隔离**：假设族、α 预算、错误预算、判决、终局条款——全部独立；两程序互不引用对方结果作为自己的证据。
**移交**：SFW 事件的谱系被 vendor 概念覆盖（M2 映射，Jaccard ≥ 0.5）后，该题材的后续再激活归 SFL 管辖；SFW 只做出生到成熟前段。

## §12 已知局限登记（诚实边界）

1. U2-born 臂的准入循环性经时滞分离缓解但未消灭（§5.3），永久挂旗分层报告；
2. 日频合同对 D0–D2 执行是结构性粗粒度，W2 的 `R_executed` 在第一浪场景是弱估计（§8.2），L1 晋级是后续程序而非本程序补丁；
3. 认知延迟差 alpha 按构造衰减，本程序全部结论带时效（§0.2）；
4. 文本源可回溯性未验前不承诺 U0 臂回测长度（§1.2 G-T）；
5. EVENT 型（买预期卖事实）是另一种游戏，本期只分层登记不定制（§6.4）。

**终局条款**：若 H-W0 在 OOS-B 后 FAIL，或 G-W1 不可校准，或 `R_buyable` DEV 期系统性 ≤ 0——SFW-1 关闭，结论固化为"第一浪在日频数据合同下不可交易"，唯一合法后续是 L1 粒度下的新程序立项，不得以参数微调续命。本条款与 SFL 终局条款互不构成对方的延期理由（宪法第八条）。

## §13 实施 Agent 要点

1. 先过 G-DQ [继承] 与 G-T（§1.2）两道门，任一 FAIL 写 `GATE_FAILED.flag` 硬停；
2. 建 LAC 机器（§4）并先跑零世界诞生率校准（§7）——**阈值反解先于任何真实数据上的事件检测**；
3. U0 文本管道按可回溯性分段（§9）；
4. 事件检测 → 三口径记账（§0.3）→ 法庭（§8）→ 双 Agent 哈希验收；
5. 全程 append-only；本表（§11）之外无自由参数，遇到未冻结的决策点：停下、登记、报告，不得自行裁量。

## 1. 用户提出的逻辑（原文要义）

> 抄底（预测底部转折点）不可能、低概率；只能确认底部转折已发生——付出一段成本，换取确定性与概率。同理，退出不应预测何时到顶（捉顶），而应确认"顶部转变已发生"——同样有一系列状态转变可依循，同样付出回撤成本，换取更高确定性。

## 2. Critical Review 结论：认识论对称成立，经济学对称断裂于四处

### 2.1 成立的部分
顶部与底部同样由未公开信息形成，公开量价只能记录不能先于；"确认已发生"替代"预测将发生"在退出侧严格同构。趋势跟踪行业的退出端（跟踪止损/破位确认）即此结构的六十年实证。"放弃鱼头"与"放弃鱼尾"是同一个承认的两次应用。

### 2.2 断裂点一：顶部确认保费更贵且更黏
- 底部保费 = 踏空成本（温和、可执行）；顶部保费 = 回撤成本，被两个因子恶化：
  - **负偏**：A 股板块退潮速度常为主升的 2-3 倍（尖顶结构），确认滞后每天更贵；
  - **黏性**：顶部确认触发时刻 = 全市场退出信号共振时刻，T+1 + 跌停 → "确认了却卖不掉"（V11 §8A.4 顺延），底部无对称的执行锁死。

### 2.3 断裂点二：镜像指标栈存在，但每级信噪比更低
```
底部栈:  低拥挤区间 → 涨停点火 → 量能持续 → 广度低位跳升 → 价格向上穿越
顶部栈:  高拥挤区间 → 涨停结构衰竭(晋级率崩塌/炸板率升) → 量价背离(新高缩量)
         → 广度高位崩落(价新高而参与度下降) → 价格向下破位
```
更噪的原因：行情中段的正常洗盘产生与顶部相同的短期形态；底部的对照状态是死寂基态（对比度高），顶部的对照状态是活着的趋势（对比度低）。解法与进场同构：**区间条件 × 跃迁事件复合**——"拥挤度高分位区间"且"广度自峰值崩落"才是顶部确认。份额分位一变量两端用：<0.50 是进场哨兵，>0.90 是退出哨兵。

### 2.4 断裂点三（最重要）：用户框架合并了两个不同的退出问题
"确认顶部"预设有顶部存在（进场是对的）。但假启动没有顶部可确认——它只是死了。只有顶部确认腿的退出系统，假启动仓位无限流血。完整退出系统须确认三件不同的事（均为"确认已发生"）：

| 腿 | 确认什么 | 逻辑 |
|---|---|---|
| A 失败确认 | "启动是假的"已发生 | 进场论点预言的扩散在自然时窗内未兑现——确认预期状态的缺席 |
| B 顶部确认 | "行情走完了"已发生 | 区间条件（高拥挤）× 跃迁事件（广度崩落 + 价格破位） |
| C 论点过期 | "信号信息衰减殆尽" | A、B 均未触发时的时间兜底（期限结构规定信号半衰期有限） |

副产品：A 腿截断全事件分布的左尾，对净期望的贡献可能大于 B 腿（假启动数量通常多于走完整行情的真启动）。

### 2.5 断裂点四：假顶确认的悔恨不对称
假底确认（假启动进场）代价 = 小额止损；假顶确认（把洗盘当顶）代价 = 丢掉行情后半段或付重进场往返摩擦（重进场规则又是一窝新参数）。例证：2020-2021 新能源行情中途多次拥挤警报，警报即清仓者错过其后主升段。推论：
- 顶部确认阈值必须比进场确认更保守（更多条件 AND）；
- **区间信号管仓位（减仓），跃迁信号管去留（清仓）**；
- 左侧减仓在拥挤高潮的流动性盛宴中执行（卖给亢奋对手盘，便宜），破位确认时只剩半仓挤右侧的门——结构性缓解断裂点一的执行问题。

## 3. EXIT-3C 方案定义

设计约束：最大限度复用已冻结参数（P4/P9/P12/P13），新增自由度 3 个；作为 Level-2 **P1c 变体**与 P1（固定 20 日空退出）、P1b（纯 ALARM 退出）并列受审。

```
持仓状态机（进场后逐日评估，信号计算用 ≤D 数据、D+1 执行）:

Leg A 失败确认（进场后前 10 个交易日内）:
    Breadth_s < 0.30            # P12 复用：跳变的基数线被收复
    → 确认假启动，全仓退出
    新参数①: 失败观察窗 W_fail = 10 交易日

Leg B1 高潮减仓（区间型，左侧，任意时点）:
    CrowdPctl_s > 0.90          # P4 复用 = ALARM
    → 减至半仓（仅触发一次，不反复加减）
    新参数②: 减仓比例 = 50%

Leg B2 顶部确认（跃迁型，右侧，任意时点）:
    ( Breadth_s ≤ max(Breadth_{s, 进场日:D}) − 0.20 )   # P13 镜像复用
    AND ( RS20_s < 0 )                                   # P9 复用：相对强度转负
    → 确认顶部已发生，余仓全部退出

Leg C 论点过期（兜底）:
    A、B2 均未触发满 60 个交易日   # T1 最长测量期限复用
    → 全仓退出
    新参数③: 最大持有期 = 60 交易日

优先级: A > B2 > B1 > C（同日多触发取先）
执行约束: 全部卖出按 D+1 收盘价（板块指数代理阶段）；
          个股化阶段须走 §8A.4 顺延规则（跌停卖不出诚实建模）
```

## 4. 裁决协议（先验，禁止事后挑）

- 比较对象：P1c vs P1（空退出基线）vs P1b，同一事件集合、同一成本假设；
- 三维同时判定：**全事件净期望**、**左尾 CVaR(5%)**、**换手摩擦总额**；
- 通过线：P1c 净期望 > P1 且 CVaR 不劣于 P1；仅在部分维度占优 → 如实报告、维持 P1 为默认；
- 附加诊断（不设通过线）：各腿触发占比、各腿贡献分解（A 腿避损 / B1 减仓避损 / B2 尾段放弃额 / C 兜底占比）；
- **先决条件**：先读 T1 期限结构。若平均中段仅 15-20 日，确认退出的回撤保费大概率吃掉中段、固定 k 胜，P1c 预期失败——该预期在此登记，届时失败不得归因于"参数没调好"而追加调参。

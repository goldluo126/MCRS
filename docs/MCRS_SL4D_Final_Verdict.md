## 1. 装置合格性认定

## 3. 机制结论：确认保费超过了剩余中段

剂量反应倒 U（0→2 升、3→4 崩，score 4 = −1.28%）与 T7 梯度（P6=1.2 放松 → +0.49%；P6=1.5 收紧 → −1.85%；P12=0.25 放低 → +0.54%）指向同一机制：**每加深一层确认，入场更晚，20 日窗口内剩余中段更少；四维全通的角点上，确认保费已超过全部剩余中段。**"确认有价格"的理论获得定量验证；其策略含义是否定的——2018-2024 的 A 股轮动速度下，市场对"四重确认后持有 20 日"的报价为负。

## 4. 研究线状态（贝叶斯账本）

两个独立设计家族（V3-V8 Launch Index 谱系六版；SL-4D 两轮）、前后八次尝试，无一在成本前信号层同时取得显著性与效应量。装置已经安慰剂验证，测量借口用尽。零假设——"公开日频量价数据在板块粒度、20 日尺度上不存在跑赢等权持有的启动择时优势（至少 2018-2024）"——多次先验登记的谋杀尝试后存活。V12 §5.4 停止条件（连续多版本失败 / 简单基准持续占优 / 效应量极小）全部满足。

## 5. 裁定

1. **SL-4D 实验正式关闭**，判词：DEV 证伪、装置合格；
2. **OOS-A（2015-2017）/ OOS-B（2025-2026H1）锁箱保持密封，不予授权开启**。理由：S1 判定标准要求 DEV 通过且 OOS 同号，DEV 已 FAIL，OOS 对 SL-4D 零决策价值；锁箱纯洁性是项目最有价值的剩余资产；H2' 若值得终审，应由正式定义的拥挤度信号规格出庭，而非死亡复合信号的消融表；
3. `sl4d-v2-freeze` 为本实验最终状态；EXIT-3C 提案（未登记）随实验关闭自动作废，其分析价值保留于文档；
4. 验证 Agent v2 执行记录为合格范本（闸门强制、安慰剂前置、见败不调参、锁箱不动），留档。

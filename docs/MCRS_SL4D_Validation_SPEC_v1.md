## 0. 一页纸摘要

**待检验命题**：A 股"板块启动"不是单一指标事件，而是四个正交维度共同确认的状态——

> ① 低拥挤基态（份额分位当条件） × ② 量能点火（自体量比） × ③ 价格确认（价格穿越） × ④ 广度扩散（板块内广度低位跳变，核心裁决）；⑤ 涨停结构为 A 股特色增强项。

**核心假设（可证伪形式）**：

| ID | 假设 | 证伪条件 |
|---|---|---|
| H1 | 四维复合信号触发后，板块未来 20 日相对等权全板块基准存在正超额收益 | 20 日超额收益 Block Bootstrap 95% CI 含 0，或 Cohen's d < 0.2 |
| H2 | ④广度低位跳变是四维中信息量最大的一维 | 消融实验中，去掉 C4 对 20 日超额收益的损伤 **不是** 四个 leave-one-out 变体中最大的 |
| H3 | ①低拥挤条件有增量价值（防"高潮误判为启动"） | 去掉 C1 后信号组表现无恶化（超额均值下降 < 10% 且假阳性率无上升） |
| H4 | 拥挤度极值（份额分位 > 0.90）是负向预警：该状态下未来 20 日超额收益 ≤ 0 | 高拥挤组 20 日超额收益显著为正 |
| H5 | "量增价增但高拥挤/无广度扩散"是假启动（对用户原方案的直接检验） | 该组表现不劣于四维全通组 |
| H6 | 信号有效性状态依赖（牛市有效性 ≠ 熊市） | 牛熊分层无显著差异（此假设允许双向结果，仅要求如实报告） |

**验证分两层**：Level-1 信号层事件研究（主要证据），Level-2 端到端组合回测（次要证据，成本后 vs 等权全板块）。**Level-1 不成立则 Level-2 不必做。**

**诚实边界（先验声明）**：本实验检验的是信号信息含量，不是可上线策略。即使全部假设成立，结论也仅为"信号携带成本前/成本后信息"，距实盘还差 MCRS §15 的 G2-G5 全部闸门。本 SPEC 不给出任何预期收益数字（V12 教训 #1）。

## 2. 信号定义（全部阈值先验冻结）

以下所有量在交易日 D **收盘后**用 ≤D 的数据计算。可执行时点为 D+1（防 same-day 前视，V12 教训 #5/#20）。

### 2.0 冻结参数总表

| ID | 参数 | 冻结值 | 先验理由 |
|---|---|---|---|
| P1 | 拥挤度滚动窗 | 250 交易日 | 约 1 年，覆盖一个完整申报/财报周期 |
| P2 | 份额平滑窗 | 20 日均值 | 抹平单日事件脉冲 |
| P3 | 低拥挤门槛 | 分位 < 0.50 | "中位数以下才有启动空间"，无更精细先验则取中位 |
| P4 | 高拥挤警报 | 分位 > 0.90 | 极值定义，对齐 V11 原 SMA 的 Q0.95 精神但留缓冲 |
| P5 | 量比基准窗 | 20 日 | 月度量能基准 |
| P6 | 量比门槛 | ≥ 1.3 | 显著高于日常波动（约 +1σ 量级）且非极端 |
| P7 | 量比持续性 | 连续 3 日 | 排除单日事件脉冲（对用户原方案缺陷三的修复） |
| P8 | 价格突破窗 | 60 日新高 | 季度级平台突破 |
| P9 | 相对强度窗 | 20 日 | 月度 RS |
| P10 | RS 穿越回看 | 5 日内由 ≤0 转 >0 | "穿越事件"而非"排名靠前" |
| P11 | 广度定义 | 成分股 close_qfq > MA20 占比 | 最通用的参与度定义 |
| P12 | 广度低基数 | D-5 时 < 0.30 | "低位"定义：不足三成参与 |
| P13 | 广度跳变幅度 | 5 日内 ≥ +0.20 | 一周内两成成分股新加入，扩散强度 |
| P14 | 涨停窗口 | 最近 5 日 | 点火-发酵周期的发酵段 |
| P15 | 涨停判据 | 5 日内涨停事件 ≥ 3 且涉及 ≥ 2 只不同个股 | 排除单股一字板（重组/借壳噪声） |
| P16 | 事件去重间隔 | 20 交易日 | 与主评估期一致，保证事件独立性 |
| P17 | 主评估期 | 20 交易日（辅 5/10/60） | 对齐 v3 已证实的信号半衰期量级 |
| P18 | 牛熊分界 | 沪深300 收盘 vs 自身 MA200 | 最少参数的状态定义 |

### 2.1 维度 C1：低拥挤基态（条件）

```
Share_{s,D}      = SectorAmount_{s,D} / Σ_{31板块} SectorAmount_{·,D}
Share20_{s,D}    = mean(Share_{s, D-19:D})                    # P2
CrowdPctl_{s,D}  = rank_pct(Share20_{s,D} within Share20_{s, D-249:D})   # P1，纯回看
C1 = CrowdPctl_{s,D} < 0.50                                   # P3
ALARM = CrowdPctl_{s,D} > 0.90                                # P4（用于 H4/H5，非买入维度）
```

SectorAmount 优先用官方 `sw_daily.amount`（经 G-DQ3 校验），单位统一为元。

### 2.2 维度 C2：量能点火（触发）

```
VolRatio_{s,D} = SectorAmount_{s,D} / mean(SectorAmount_{s, D-20:D-1})   # P5
C2 = ( VolRatio_{s,t} ≥ 1.3  对 t ∈ {D-2, D-1, D} 全部成立 )            # P6, P7
```

### 2.3 维度 C3：价格确认（触发）

```
C3a = Close_{s,D} ≥ max(Close_{s, D-60:D-1})                  # P8 平台突破
RS_{s,D} = Close_{s,D}/Close_{s,D-20} - HS300_D/HS300_{D-20}  # P9
C3b = ( RS_{s,D} > 0 ) AND ( min(RS_{s, D-5:D-1}) ≤ 0 )       # P10 由负转正穿越
C3 = C3a OR C3b
```

价格用官方申万指数收盘价（点位序列自洽，无需复权）。

### 2.4 维度 C4：广度扩散（核心裁决）

```
对可交易成分 i ∈ T_s(D)（PIT，§1.3）：
Breadth_{s,D} = |{ i : close_qfq_{i,D} > MA20(close_qfq_i)_D }| / |T_s(D)|   # P11
C4 = ( Breadth_{s,D-5} < 0.30 ) AND ( Breadth_{s,D} - Breadth_{s,D-5} ≥ 0.20 )  # P12, P13
```

证伪保护：|T_s(D)| < 5 时该板块当日全部信号 INVALID（对齐 V11 §3.1 证伪条件）。

### 2.5 维度 C5：涨停结构（A 股特色增强，可选项）

```
LU_{s,t} = |{ i ∈ T_s(t) : close_raw_{i,t} ≥ up_limit_{i,t} }|     # stk_limit 查表
C5 = ( Σ_{t=D-4}^{D} LU_{s,t} ≥ 3 ) AND ( 涉及不同个股数 ≥ 2 )      # P14, P15
```

### 2.6 复合信号与事件定义

```
LAUNCH_{s,D}  = C1 AND C2 AND C3 AND C4          # 基础四维
LAUNCH+_{s,D} = LAUNCH AND C5                     # 涨停增强版
```

**事件**：板块 s 在日 D 首次触发 LAUNCH（或对照变体），且距该板块上一事件 ≥ 20 交易日（P16）。事件锚点 = D，可执行入场 = D+1 收盘价（官方指数）。

**前视偏差检查清单（每个信号 MUST 通过）**：
- [ ] 所有分子分母仅用 ≤D 数据；滚动分位仅回看，绝不用全样本分布；
- [ ] 入场价用 D+1，事件收益从 D+1 收盘起算；
- [ ] MA20/广度用前复权价；涨停判定用未复权价 + stk_limit；
- [ ] 成分为 PIT 三源合成，禁用当前成分回填历史。

## 3. Level-1 信号层检验（主要证据）

### 3.1 T1 主事件研究

对每个 LAUNCH 事件计算前瞻超额收益：

```
FwdRet_k   = IndexClose_{s, D+1+k} / IndexClose_{s, D+1} - 1,   k ∈ {5, 10, 20, 60}
ExcessEW_k = FwdRet_k - EW31Ret_k        # 主基准：31板块等权（每日再平衡，零成本，从严）
ExcessHS_k = FwdRet_k - HS300Ret_k       # 副基准
```

**统计方法**（V12 教训 #12/#13）：
- 事件级：Block Bootstrap（block=5, n=10000）对 ExcessEW_20 均值构造 95% CI；报告均值、中位数、胜率、**Cohen's d**；
- 日历时间法（处理事件同日聚集的横截面相关）：构造"活跃事件组合"日度序列（每日等权持有事件后 ≤20 日的板块），对其日超额收益做 Newey-West t 检验（lag=10）+ Block Bootstrap，两法并报；
- **样本量闸门**：DEV 区间 LAUNCH 事件数 < 30 → 报告统计功效不足，H1 判定为 INCONCLUSIVE，不得强行下结论。

### 3.2 T2 消融实验（检验 H2/H3：广度是否核心、拥挤是否有增量）

在 DEV 区间对以下 9 个变体跑与 T1 相同的流程：

| 变体 | 定义 |
|---|---|
| FULL | C1∧C2∧C3∧C4（基准） |
| DROP-C1 / DROP-C2 / DROP-C3 / DROP-C4 | leave-one-out 四个 |
| ONLY-C1 / ONLY-C2 / ONLY-C3 / ONLY-C4 | 单维度四个 |

报告：每变体的事件数、ExcessEW_20 均值 / d 值 / 胜率。**H2 判据**：`ExcessEW_20(FULL) - ExcessEW_20(DROP-C4)` 在四个 leave-one-out 差值中最大（按点估计排序判定，消融属描述性比较，不做多重检验显著性声明——先验声明以避免 p-hacking 争议）。**H3 判据**：DROP-C1 相对 FULL 的均值下降 ≥ 10% 或胜率下降 ≥ 5pp。

### 3.3 T3 拥挤度警报检验（H4）

事件定义：`ALARM`（CrowdPctl > 0.90）首次触发（同样 20 日去重）。检验其 ExcessEW_{5,10,20,60} 是否 ≤ 0（Bootstrap CI）。这是"天量天价该规避"的直接检验。

### 3.4 T4 假启动对照（H5，对用户原方案的判决性检验）

构造对照组：**"量增价增但缺基态/广度"** = C2∧C3 成立，且（C1 不成立 或 C4 不成立）。
对比该组与 FULL 组的 ExcessEW_20 分布（Bootstrap 均值差 CI）。
- 若 FULL 显著优于对照组 → "低拥挤 + 广度扩散"的条件确有过滤假启动的价值；
- 若两组无差异 → 我的四维论被证伪一半，用户的两维方案（量增价增）不劣，MUST 如实报告。

### 3.5 T5 状态分层（H6）

以 P18（HS300 vs MA200）把每个事件标记为 BULL/BEAR，全部 T1-T4 指标分层重算并列报告。不设通过线，只设**如实报告义务**：若信号仅牛市有效，结论 MUST 写"牛市条件信号"，不得写"全天候信号"。

### 3.6 T8 安慰剂检验

- 时移安慰剂：全部信号后移 20 交易日，重跑 T1，效应 MUST 消失（|d| < 0.1）；
- 随机日期安慰剂：每板块随机抽取与真实事件同等数量的日期（牛熊比例匹配），重复 1000 次构造 ExcessEW_20 零分布，真实均值 MUST 落在零分布 95 分位之外（单侧）。

## 4. Level-2 端到端组合检验（次要证据；T1 的 H1 不成立则跳过本节）

### 4.1 组合规则（先验冻结，禁止事后调整）

| 项 | 规则 |
|---|---|
| 入场 | LAUNCH 事件 D+1 收盘按官方指数买入（指数代理，局限见 4.3） |
| 持有期 | 固定 20 交易日后 D+21 收盘卖出；**变体 P1b**：持有期内 ALARM 触发则次日收盘提前卖出（检验警报的组合价值） |
| 并发上限 | 5 个板块；超出时按 ΔBreadth（5 日跳变幅度）降序取前 5 |
| 权重 | 活跃持仓等权；空仓部分持现金（收益记 0，从严） |
| 状态变体 P2 | 同 P1，但 BEAR 状态（P18）不新开仓，已有持仓自然到期 |
| 成本 | 买入 0.125%、卖出 0.175%（佣金+印花税+冲击的板块级摊销近似），**毛/净并报** |
| 基准 | ① 31 板块等权（每日再平衡，零成本，从严对标）；② HS300；③ 纯现金 |

### 4.2 必报指标

分 DEV / OOS-A / OOS-B / 全期 与分年度：毛收益、净收益、年化波动、Sharpe、最大回撤、年换手率、持仓天数占比、事件数；对等权基准的周频超额收益 Cohen's d；牛熊分层。

**先验声明（V12 教训 #4/#7）**：基于 V6/V7 前证，组合层净收益跑输等权全板块是**高概率、可接受、有价值的结果**——它意味着"信号有信息但不足以覆盖轮动成本"，这本身就是结论。验证 Agent MUST NOT 因组合跑输基准而回头改信号参数。

### 4.3 已知局限（MUST 写入报告）

- 指数代理高估可执行性：板块启动初期龙头个股常涨停买不进，指数收益含不可成交部分。本实验停留在信号层证据（G0-G1 级），不作可上线声明；
- 板块级摊销成本是近似，个股级执行成本只会更高（结论只会更保守，方向安全）。

## 6. 成功/失败判定（先验冻结）

| 判定 | 条件（全部基于 ExcessEW_20 主口径） |
|---|---|
| **S1 信号成立** | DEV 区间：FULL 组 Bootstrap 95% CI > 0 且 d ≥ 0.2 且事件数 ≥ 30；且 OOS-A、OOS-B 点估计符号均为正 |
| **S2 广度核心成立** | T2 中 DROP-C4 造成的损伤最大（点估计排序） |
| **S3 拥挤警报成立** | T3 中 ALARM 组 ExcessEW_20 点估计 < 0 且 CI 上界 < ExcessEW_20(FULL) 点估计 |
| **S4 四维优于两维** | T4 中 FULL 与"量增价增对照组"的均值差 Bootstrap CI > 0 |
| **S5 组合层价值** | Level-2 净收益的周频超额（vs 等权基准）d ≥ 0.2（预期大概率不成立，不成立不推翻 S1-S4） |

**最终判词模板（报告结尾 MUST 按此逐条填写，禁止综述式含糊）**：

```
S1 信号成立:      PASS / FAIL / INCONCLUSIVE + 一句话证据
S2 广度核心:      PASS / FAIL + 消融排序表
S3 拥挤警报:      PASS / FAIL + ALARM 组 CI
S4 四维>两维:     PASS / FAIL + 均值差 CI
S5 组合层价值:    PASS / FAIL / SKIPPED + 净收益 vs EW
安慰剂:           PASS / FAIL
稳健性:           PASS / FAIL + 符号翻转的参数清单
OOS 一致性:       OOS-A [+/-]  OOS-B [+/-]
诚实结论（≤5 句）: 不得使用"验证了框架有效"之类的综述语言；
                  只允许陈述哪些假设在什么区间以什么效应量成立/不成立。
```

**停止条件**（触发即停止并上报，不得继续迭代）：数据质量闸门失败；DEV 事件数 < 30；发现任何前视偏差；任何"想调参数再跑一次"的冲动（V12 教训 #2——这是本实验最大的失败风险）。

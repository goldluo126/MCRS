## 3. 零模型与状态机

### 3.1 主零模型：同日分层条件置换（v5 反转 v4 选择）

```
分层（PIT，D 日）: 交易板块 × 流通市值三分位 × 20日波动三分位 × 20日动量三分位 × 股性三分位
  （层内不足 8 只时逐级粗化：先并动量、再并波动——粗化序冻结）
置换: 保留当日各层真实涨停股数，层内随机重排涨停标签；B = 2000，种子 = 42
题材经验尾概率: p_emp(c,D) = (1 + #{置换中 LU_perm ≥ LU_real}) / (1 + B)
LUShock(c,D) = −log10( p_emp )
```
- **语义**：在当日同样的市场情绪、规模/波动/动量结构与真实涨停总量下，该题材成员共同涨停是否仍然异常——市场级与风格级共同冲击被构造性吸收；
- **族校准（多重扫描控制）**：每次置换同时记录全部休眠题材的 max LUShock，得当日 maxT 分布；**点火要求：LU_real ≥ 2 ∧ LUShock ≥ 当日 maxT 分布 95 分位**；年度预期伪 Episode 数必报；
- **Poisson-binomial 降为实时快速筛**（异质倾向口径沿 v4）：仅用于盘中/低延迟预警；与主口径分歧标 `null_model_disagreement`，该事件不得计为高可信协调事件；
- 命名纪律：本口径称"条件经验零模型"；PB 称"给定估计概率与条件独立假设下的精确计算"，MUST NOT 称"精确零模型"。

### 3.2 状态机（v5 修订三处）

- **信号计算单元 = native concept**；Cluster 仅用于去重/资金/推断聚类；同簇同日多概念点火 → 取族校准 LUShock 最高者为获胜概念，EpisodeBaseSet = 获胜概念的 D−1 成员（非簇并集）；
- DORMANT / IGNITION（Members_{D−1}）/ MATURITY 沿 v4；
- **CONFIRMATION 反单股伪造**（v5）：
  ```
  确认 = EpisodeAge ∈ [1,4] 内 [ 扩散（LUShock≥当日maxT 80分位 ∧ 新增涨停成员≥1）
         或 晋级（MaxBoard 抬升 ∧ 连板链起点 ≥ D0−1 ∧ 独立活跃成员 ≥ 2）]
         ∧ BombRate ≤ 0.5（触板≥3 时）
  ```
  单只妖股连板不得确认整个题材；
- 夭折点火全量入库（Policy I 与 E2 的组成部分）。

## 5. 法庭与目标试验

### 5.0 目标试验纪律（v5 新增）
每个实验 MUST 在实现前冻结九要素表：Eligibility / Assignment time / Treatment / Control / **Time zero** / Follow-up / Outcome / Estimand / **Switching 规则**。对照题材随访期内自行点火的处置：**主口径 ITT**（D0 未点火即终身对照，衰减方向保守）；副口径 per-protocol（对照点火日删失）。

### 5.1 第一法庭：题材层（零 ZJ）

- **双 estimand（v5 新增）**：
  - 科学效应：EpisodeBaseSet 可交易成员**全体等权**；
  - 可投资效应：固定容量子集（ADV20 ≥ 1 亿 ∧ D+1 非开盘涨停；非 ZJ 条件）等权；
  - 2×2 结论表：科学✓可投✓=机制与策略双成立；科学✓可投✗=注意力 alpha 集中于不可承载股；科学✗可投✓=警报（载体可能只是独立动量）；双✗=失败；
- 匹配沿 v4（D0−1 冻结协变量、伪时钟）+ **平衡闸门（v5）**：审计协变量（匹配 4 项 + 市值/波动/涨停倾向/题材年龄/换手/标签泛化度）全部 |SMD| ≤ 0.10，超限配对剔除；剔除 >30% → MATCH_BALANCE_FAILED；k=1 有放回，单控制复用 ≤3 次（频数权重）；
- **主推断（v5 修订）**：配对差值 + (canonical_cluster × 事件日) 双向聚类 bootstrap；**P2 触发置换降为敏感性诊断**（观察性匹配无可交换性，不作正式 p 值）。

### 5.2 确认价值：政策比较（v5 核心新增，取代 NetConfirmationValue 代数）

```
Policy I（点火政策）: 全部点火题材 D0+1 买入（含日后夭折者），持有 10 日
Policy C（确认政策）: 点火后等待 ≤4 日；确认成功 Dconf+1 买入持有 10 日；夭折持现金
Policy M（匹配对照）: 匹配题材按伪时钟同规则
ValueOfConfirmation = Return(C) − Return(I)     # 自动内含筛选收益、延迟损失、资金空置与交易次数差
```
分解诊断（不作主判据）：E1（点火 vs 休眠未点火，D0+1 起）；**E2 landmark 版：D0+4 收盘分类 confirmed/failed，两组统一自 D0+5 起测 5/10/20 日**（确认形成期收益 MUST NOT 计入确认效果——v4 的机械偏差修复）；E3 双口径：入场价差 R(D0+1→Dconf+1) 与共同终点 R(D0+1,Dconf+10) − R(Dconf+1,Dconf+10)。

### 5.3 第二法庭（沿 v4 + §4 闸门修订）：T_ZJ / B（精确枚举）/ C0 / N / 影子 L。

### 5.4 第四法庭（v5 修订）：T_sys vs A_sys（纯度主资格为在籍条件，A_sys 天然可构造；文本不进池）+ **经济基准组**：① 规模/ADV 匹配随机组合；② 全 A 容量可交易等权；③ 现金与沪深300。A_sys 是归因对照，经济判决以基准组为准。

## 9. 统计、MES 与功效

### 9.1 推断
NW lag = max(2×持有期, auto)；stationary bootstrap 期望块长 20；(canonical_cluster × 事件日) 双向聚类；触发频率闸门沿 v4。

### 9.2 分法庭 MES（v5 修订，废除单一 50bp∧d 混尺度）
| 法庭 | MES |
|---|---|
| 一（题材） | 10 日成本后配对超额 **50bp/事件** |
| 二（载体） | 10 日相对同池随机 **20bp/事件** |
| 三（退出） | 净期望改善 >0 ∧ CVaR(5%) 不劣 |
| 四（系统） | **年化净 alpha ≥ 3%**（vs 经济基准组） |
d = 0.2 仅作描述统计与功效规划输入，不作判决条件。

### 9.3 四分法判词（v5 修订，堵 CI 下界>0 但<MES 的漏洞）
| 判词 | 条件 |
|---|---|
| Statistically Positive | CI 下界 > 0 |
| **Economically PASS** | **CI 下界 > MES** |
| Economically FAIL | CI 上界 < MES |
| INCONCLUSIVE | CI 跨越 MES |
判词组合合法（如"统计为正但未达经济门槛"）；家族死亡仅由影子第一法庭 Economically FAIL 触发。

### 9.4 功效仿真与序贯影子法庭（v5 核心新增）
- **Freeze 前 MUST 完成功效仿真**（输入 = DEV 的方差/相关结构等冗余参数，非主效应结果）：模拟在配对差值方差、簇内相关、事件频率下，对各法庭 MES 达 80% 功效所需独立 Episode 数 n_target；**n_target 如实冻结，即使意味着影子期数以年计**；
- **成组序贯设计**：中期分析于 n_target 的 1/3 与 2/3 处 + 终期，O'Brien-Fleming 型边界（冻结）；效应大可提前 PASS/FAIL，否则等到 n_max；中期分析由判决规则自动执行，不得人工加看；
- 市场状态覆盖：每状态独立簇 **n ≥ 10 且占比 ≥ 15%（同时满足）**。
